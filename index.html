  • 多引擎搜索 集成 Google、百度、Bing、DuckDuckGo、Yahoo 五种搜索引擎，实时切换，支持搜索建议（Bing API）与历史记录
  • 磁贴系统 可自定义的图标磁贴（Font Awesome 图标库 / 本地上传图片 / Emoji），支持拖拽排序、右键编辑删除、长按进入编辑模式
  • 分类页面 多页面分类管理，可通过空白区域右键新建/删除分类，支持拖拽重排分类顺序，分类名称支持双击重命名
  • 三套主题 亮色、晨雾、暗色三种视觉主题，右上角齿轮设置或右键菜单中切换
  • 自定义背景 支持上传图片或视频作为背景，可调节遮罩透明度与视频帧率，一键重置默认背景
  • 专注模式 偏右上角点击时间进入隐藏态——轻专注保留搜索仅隐藏分类和磁贴，深专注全部收起；再次点击时间恢复
  • 分类按钮行 可选显隐的水平分类按钮栏，支持快捷切换页面
  • 自动聚焦 新标签页打开时自动聚焦搜索框（可配置开关），支持 / 键快捷聚焦
  • 分类记忆 记住上次离开时的分类页面，下次打开自动恢复（可配置开关）
  • 快捷方式调节 设置面板中可切换磁贴大小（小/标准/大）和每排数量（6/8个）
  • DevHome 开发工作台 右键打开独立工作台面板，展示当前焦点项目、Inbox 收件箱、项目列表与资源入口，支持搜索项目、资源和命令
  • Popup 预览模式 在工作台面板中内置 Popup 快速操作预览页，可在一处查看书签、历史、下载等核心能力
  • 数据备份 支持导出全部配置到 JSON 文件备份，支持导入恢复（覆盖当前配置）
  • 键盘快捷键 / 聚焦搜索、Esc 退出/关闭面板、Ctrl+B 打开弹窗、Ctrl+K 打开工作台、Alt+1~5 切换搜索引擎、1~5 切换搜索引擎、Enter 执行搜索、Tab 切换页面
  • 扩展弹窗 点击工具栏图标或 Ctrl+B 打开 Popup，支持综合搜索、书签管理、历史记录查看、下载管理，带键盘导航
  • Popup 设置 弹窗内可配置默认标签页、主题色、书签排序方式、日期折叠分组、删除确认等
  • 浏览器集成 利用 Chrome storage、bookmarks、history、downloads、tabs API 实现数据同步与功能集成
  • 视觉效果 CSS 自定义属性体系、毛玻璃面板、网格背景、渐变动画过渡、响应式布局支持
