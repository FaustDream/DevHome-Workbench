更新说明

v2.1.0 2026-06-23
  • 富文本编辑器 contenteditable 替代 textarea，工具栏支持标题1-6、加粗、斜体、下划线、有序/无序列表、20色颜色面板、高亮背景
  • 代码块 右键菜单支持插入代码块，20种编程语言标签
  • 类型多选 文章可同时归属多个类型（笔记/想法/Bug/会议/剪藏），类型徽章支持 chip 化增删
  • 日期标签 新建文章自动附加年月日标签，侧边栏按日期分组（今天/昨天/周几）
  • 右键菜单 专注模式下隐藏磁贴/分类操作；编辑器内右键弹出格式菜单（标题/加粗/颜色/代码块）
  • 禁止原生弹窗 全部 alert/prompt 替换为主题化组件，新增 showPrompt / showToast
  • 交互日志 所有可点击功能输出控制台日志，标记 [交互][面板][编辑][警告] 前缀便于排查
  • 修复 编辑器内数字键被误拦截切换搜索引擎
  • 修复 自定义弹窗在日常模式下裸露显示
  • 修复 工具栏按钮点击后选区丢失导致格式无效
  • 修复 颜色面板被 overflow:hidden 裁剪不可见
  • 导航 Tab"总览"更名为"工作台"
v2.0.0 2026-06-22
  • 核心重构 双模式架构：日常像素主题 + 专注暖纸主题，通过 CSS <link> 动态切换互不污染
  • 多 Tab 工作台 专注模式下顶部导航栏：总览（快速捕获 + 四象限）/ 记录（笔记编辑）/ 日历（月视图）/ 番茄钟
  • 四象限任务 艾森豪威尔矩阵，支持任务增删、拖拽移动、完成/取消标记、活跃/全部筛选
  • 笔记系统 Markdown 编辑 + 预览，笔记/捕获混合列表，类型筛选，全文搜索，自动保存
  • 番茄钟 预设/自定义时长、默认/专注模式、休息时长、进度环、今日历史
  • 日历视图 月度日历，标记有内容的日期，点击查看当日笔记和捕获
  • 网页剪藏 右键菜单 + Ctrl+Shift+S 快捷键，自动保存为剪藏类型笔记
  • AI 每日总结 腾讯混元 API，设置面板配置 Key/端点/模型，生成后一键保存为笔记
  • 导出中心 设置面板中按类型筛选，全选/导出选中为 Markdown 文件
  • 行为追踪 连续打卡、完成任务数、番茄钟数、专注分钟、笔记数统计
  • 数据存储 chrome.storage.local 主存储 + localStorage 缓存 + 文件同步（可选）
  • 快捷键 可配置专注模式快捷键，Esc 退出，Ctrl+Shift+S 剪藏
v1.3.1 2026-06-17
  • 新增 设置面板「数据」区域新增「切换配置目录」入口，更换目录后自动同步数据
  • 修复 分类选择浮窗过于灵敏 — 鼠标掠过即弹出改为需停留 200ms 后才显示，点击仍即时响应
v1.3.0 2026-06-17
  • 核心改动 新增文件系统配置持久化：用户选择本地文件夹存放配置，清除浏览器缓存/切换浏览器后可恢复全部数据
  • 搜索历史 改用浏览器原生历史记录 API，不再占用配置文件空间
  • 未授权保护 首次或目录失效时强制提示用户选择配置目录，扩展图标显示红色感叹号角标
  • 设置面板 新增「立即同步到文件」和「切换配置目录」入口
v1.2.0 2026-06-17
  • 核心改动 移除亮色/晨雾/暗色三套主题，统一为黑客像素风格唯一主题，纯黑背景
  • 数字雨重写 极慢速攻防双向流动（55%下落为攻/45%上升为防），红色警示字符混入，鼠标涟漪与字符位移互动
  • 外观透明化 时间区域、搜索栏、磁贴全部改为透明背景仅保留边框，数字雨穿透整个页面
  • 背景参数面板 新增字符大小(8-80px)、流动速度(2-20×)、字符密度(60%-100%)三个可调滑块，带实时数值显示
  • 新增 设置面板「重置设置」按钮，一键恢复默认值（保留磁贴和分类数据）
  • 修复 数字雨背景未铺满全屏（z-index 层叠 + body 宽度限制导致两边留白）
  • 修复 磁贴未居中显示（auto-fill grid 改为 flexbox）
  • 修复 CRT 闪烁动画导致持续屏闪（直接移除）
  • 修复 背景参数滑块调节后未实时生效
v1.1.1 2026-06-17
  • 修复 数字雨背景未铺满全屏，仅中间区域有效两边留白（z-index 层叠冲突 + body width 受 flex 限制）
  • 修复 快捷方式磁贴未居中（auto-fill grid 改为 flexbox 布局）
  • 修复 CRT 屏闪（body flicker 0.15s 动画）
  • 修复 数字雨脚本双 else 语法错误导致背景消失
  • 修复 背景参数滑块修改后未实时生效
v1.1.0 2026-06-16
  • 新增 设置齿轮按钮替换为更直观的齿轮造型图标，视觉识别性更强
  • 新增 设置面板中增加「更新说明」入口，点击可查看完整版本变更记录
  • 修复 Font Awesome 样式表内联 onload 事件处理器违反 CSP 策略的报错
v1.0.0 2026-06-01
  • 核心功能 全新标签页工作台，替代浏览器默认新标签页，面向独立开发者的一站式工作入口
  • 时间显示 大字号数字时钟与完整中文日期（含星期），支持大小拖拽调节
  • 多引擎搜索 集成 Google、百度、Bing、DuckDuckGo、Yahoo 五种搜索引擎，实时切换，支持搜索建议（Bing API）与历史记录
  • 磁贴系统 可自定义的图标磁贴（Font Awesome 图标库 / 本地上传图片 / Emoji），支持拖拽排序、右键编辑删除、长按进入编辑模式
  • 分类页面 多页面分类管理，可通过空白区域右键新建/删除分类，支持拖拽重排分类顺序，分类名称支持双击重命名
  • 三套主题 亮色、晨雾、暗色三种视觉主题，右上角齿轮设置或右键菜单中切换
  • 自定义背景 支持上传图片或视频作为背景，可调节遮罩透明度与视频帧率，一键重置默认背景
  • 专注模式 偏右上角点击时间进入隐藏态——轻专注保留搜索仅隐藏分类和磁贴，深专注全部收起；再次点击时间恢复
  • 分类按钮行 可选显隐的水平分类按钮栏，支持快捷切换页面
  • 自动聚焦 新标签页打开时自动聚焦搜索框（可配置开关），支持 / 键快捷聚焦
  • 分类记忆 记住上次离开时的分类页面，下次打开自动恢复（可配置开关）
  • 快捷方式调节 设置面板中可切换磁贴大小（小/标准/大）和每排数量（6/8个）
  • DevHome 开发工作台 右键打开独立工作台面板，展示当前焦点项目、Inbox 收件箱、项目列表与资源入口，支持搜索项目、资源和命令
  • Popup 预览模式 在工作台面板中内置 Popup 快速操作预览页，可在一处查看书签、历史、下载等核心能力
  • 数据备份 支持导出全部配置到 JSON 文件备份，支持导入恢复（覆盖当前配置）
  • 键盘快捷键 / 聚焦搜索、Esc 退出/关闭面板、Ctrl+B 打开弹窗、Ctrl+K 打开工作台、Alt+1~5 切换搜索引擎、1~5 切换搜索引擎、Enter 执行搜索、Tab 切换页面
  • 扩展弹窗 点击工具栏图标或 Ctrl+B 打开 Popup，支持综合搜索、书签管理、历史记录查看、下载管理，带键盘导航
  • Popup 设置 弹窗内可配置默认标签页、主题色、书签排序方式、日期折叠分组、删除确认等
  • 浏览器集成 利用 Chrome storage、bookmarks、history、downloads、tabs API 实现数据同步与功能集成
  • 视觉效果 CSS 自定义属性体系、毛玻璃面板、网格背景、渐变动画过渡、响应式布局支持
