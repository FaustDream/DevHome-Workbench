# 12 消息协议与数据流

> 本章汇总页面与 Service Worker 之间的完整消息协议、页面内数据流、存储键全景表，是排查与重构的权威参考。

## 12.1 页面 ↔ SW 消息协议（onMessage 单次）

请求均携带 `type` 判别字段（判别联合风格）。

| type | 方向 | 请求 data | 响应 |
|------|------|-----------|------|
| `POMODORO_START` | 页面→SW | `{duration, restDuration, type, taskId, taskTitle, autoCycle}` | `{success:true}` |
| `POMODORO_PAUSE` | 页面→SW | — | `{success:true}` |
| `POMODORO_RESUME` | 页面→SW | — | `{success:true}` |
| `POMODORO_STOP` | 页面→SW | — | `{success:true}` |
| `POMODORO_GET_STATE` | 页面→SW | — | `{success:true, data:{active, remaining, duration, restDuration, type, isResting, autoCycle, sessionCount, formatted, phaseStartAt, phaseTotalSeconds, taskId}}` |
| `OPEN_SIDE_PANEL` | 页面→SW | — | `{success:true}` |
| `RESOLVE_FAVICON` | 页面→SW | `{domain}` | `{success:true, dataUrl\|null}` 或 `{success:false, reason}` |
| 未知 | — | — | `{success:false, reason:'unknown_message_type'}` |

## 12.2 长连接协议（pomodoro）

| 连接名 | 方向 | 消息 |
|--------|------|------|
| `port.name='pomodoro'` | 页面建立 → SW 注册 | 每秒 `{type:'POMODORO_STATE', data:{active, remaining, formatted, ...}}` 广播 |
| 断开 | SW 移除端口 | — |

## 12.3 Chrome 通知协议（SW 独立通道）

| notificationId 模式 | 触发 | 行为 |
|---------------------|------|------|
| `pomodoro-done` | 工作完成 | 点击 → 聚焦/打开 index.html |
| `pomodoro-rest-done` | 休息结束 | 同上 |
| `task-due-<taskId>` | 任务到期/超期 | 同上 |

## 12.4 Chrome alarms 协议

| alarm 名 | periodInMinutes/when | 触发行为 |
|----------|----------------------|---------|
| `pomodoro-phase` | 动态 when（剩余秒数） | `pomodoroPhaseEnd()` |
| `task-due-check` | 固定 15min | `checkTaskDueNotifications()` |

## 12.6 核心数据流图

### 12.6.1 磁贴数据流

```
tabpage_pages / v2/pages
  → pageManager.load() → normalizePageState（修复名错位）→ state.pageNames/totalPages
  → tileManager.updateCurrentTiles() → currentTiles（按 position 排序）
  → renderTiles() → DOM
编辑：tileManager.add/update/remove/reorder → save()（position 同步下标）
  → pageManager.updateCurrentPage → pageManager.save → tabpage_pages + v2/pages
```

### 12.6.2 笔记数据流

```
创建：createNote → state.notes.unshift → storageV2.set(v2/notes) → markDirty('notes')
编辑：openNoteEditor → Tiptap onUpdate → _triggerAutoSave(400ms) → saveCurrentNote → updateNote → v2/notes
删除：deleteNote / deleteWithUndo（撤销队列）→ v2/notes
剪藏：SW clip-capture → v2/captures（或 notes）
```

### 12.6.3 任务数据流（双写）

```
addTask/updateTask → saveWorkbenchState
  ├─ devhome_workbench（localStorage 旧格式）
  └─ storageV2.set(v2/tasks)（扁平带 quadrant）
        → SW checkTaskDueNotifications（15min alarm）→ 通知
```

### 12.6.4 番茄钟数据流

```
页面 startPomodoro → POMODORO_START → SW startPomodoro
SW：phaseStartAt+phaseTotalSeconds 推导 → alarms(when) 精确切换
  → 每秒 broadcast POMODORO_STATE → 页面长连接更新 UI
阶段结束：pomodoroPhaseEnd → savePomodoroSession + 通知 + 广播
页面 pause/resume/stop → 对应消息
SW 重启：restorePomodoroState → v2/pomodoro_state → computeRemaining 恢复
```

### 12.6.5 行为统计数据流

```
renderBehaviorDashboard
  → 读 v2/behavior + v2/pomodoro_sessions
  → 计算今日番茄/专注分钟/连续打卡
  → 更新 v2/behavior.dailyStats[today].streakDay
  → window.__dashboardData → React Dashboard 渲染
```

## 12.7 消息协议重构要点

1. **消息 type 为裸字符串**：未用 TS 判别联合/常量枚举，建议统一 `MessageType` 常量表 + zod 校验（符合编码规范）。
2. **`POMODORO_START` 等消息无校验**：SW 直接信任页面输入，应加运行时校验。
3. **`RESOLVE_FAVICON` 接受任意 domain**：`fetch https://<domain>` 存在 SSRF 面（SW host_permissions 覆盖 all_urls），应白名单校验域名格式。
4. **`ai_chat_history` 无 v2 前缀**：与 v2 体系不一致。
5. **长连接消息无版本号**：前后台协议演进需兼容策略。
6. **任务双写一致性**是已知风险点（见第 06 章）。
