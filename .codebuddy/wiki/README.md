## 如何使用本文档

- **重构前**：先读 [01-项目概览与总体架构](01-项目概览与总体架构.md) 与 [02-存储与数据层](02-存储与数据层.md) 建立全局认知。
- **改某模块**：直接跳转对应章节，章节内给出该模块的挂载点、公共 API、存储键、依赖关系与关键算法。
- **排查数据问题**：查阅 [12-消息协议与数据流](12-消息协议与数据流.md) 的存储键全景表。
- **规划重构**：查阅 [13-重构改造建议](13-重构改造建议.md) 的优先级清单。

> 架构红线（必须遵守）：`lib/**` 不引用 `chrome.*`；`src/shared/**` 不引用 `chrome.*`；注入脚本必须纯函数；Popup 不直连 Native Host；跨进程只传可序列化 JSON；消息协议使用判别联合。
