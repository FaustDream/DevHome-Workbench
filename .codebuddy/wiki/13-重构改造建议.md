# 13 重构改造建议

> 本章汇总全项目扫描发现的代码味道、重构优先级与潜在风险，作为重构工作的总纲。优先级：P0=必改（正确性/安全/一致性）、P1=应改（可维护性/性能）、P2=可改（代码整洁）。

## 13.1 架构级问题（P0）

### 13.1.1 全局命名空间对象（window.DevHome）无类型约束

- **现状**：所有模块通过 IIFE 挂在 `window.DevHome`，40+ 方法无类型定义，调用方无法校验签名。
- **风险**：重构一处签名，调用方静默失效。
- **建议**：为 `ns` 定义类型接口（JSDoc `@typedef` 或迁移 TS 声明文件 `devhome.d.ts`），逐步收敛。

### 13.1.2 双存储双写（任务/磁贴）

- **现状**：任务写 `devhome_workbench` + `v2/tasks`；磁贴写 `tabpage_pages` + `v2/pages` + `v2/pageNames`。
- **风险**：写一半失败导致不一致；迁移/回滚复杂度高。
- **建议**：确立单一权威存储（建议 `v2/*`），旧格式只读兼容 + 一次性迁移，移除双写。

### 13.1.3 消息协议无校验（SW 信任页面）

- **现状**：onMessage 直接 switch 裸字符串 type，数据不校验；`RESOLVE_FAVICON` 接受任意 domain。
- **建议**：统一 `MessageType` 常量 + 判别联合 + zod safeParse；domain 白名单正则校验；SSRF 面收敛（限制协议为 https、host 白名单）。

### 13.1.4 日志体系双轨

- **现状**：`ns.logger`（info/warn/error）与大量 `console.*`（带 `[分类]` 前缀）并存。
- **建议**：全部收敛到 `ns.logger`，保留 `[分类]` 前缀约定；高敏信息（API Key）禁止入日志。

### 13.1.5 事件绑定无幂等保护

- **现状**：`bindEvents()` 重复调用重复绑定；仅个别按钮有 `_nbEventBound` 防抖。
- **建议**：统一「已绑定标记」（dataset 或 WeakMap）；高频 document 监听收敛为事件委托 + 单次注册。

## 13.6 建议的重构顺序（Roadmap）

### 阶段一：稳定底座（不改变行为）
1. 定义 `devhome.d.ts` 类型接口（ns.state / ns.dom / 各 manager）。
2. 日志统一收敛 `ns.logger`。
3. 消息协议引入 `MessageType` 常量 + zod 校验（SW 侧防御）。
4. 集中散落常量到 config.js。

### 阶段二：收敛数据层
5. 任务/磁贴双写收敛为 v2 权威，旧格式只读。
6. 修复连续打卡幂等、任务到期通知持久化。
7. 统一弹窗实现。

### 阶段三：模块解耦
8. 拆分 index.html 模板片段 + bundle 打包。
9. 事件系统幂等保护 + 委托化。
10. 天气映射表合并、QUADRANTS 集中。

### 阶段四：性能与安全
11. 磁贴/笔记列表渲染优化。
12. AI Key 加密存储；sanitizeHtml 升级；favicon domain 白名单。
13. execCommand 迁移 Clipboard API。

### 阶段五：测试补强
14. 为 `lib/` 纯逻辑（storageV2 乐观锁、countWords、cleanEmptyHTML、formatTaskTime、repairDefaultCategoryContent）补 vitest 单测。
15. 消息协议穷尽性测试；存储迁移测试。

## 13.7 需重点保护的「隐藏契约」

重构时极易破坏以下隐含依赖：

1. **脚本加载顺序**（第 11 章）：基础设施→功能→子模块→编排入口，`matrix-bg.js` 最后。改 bundle 时保持相对顺序。
2. **`ns.$$` / `ns.dom` 引用名**：HTML 结构调整须同步 state.js 的 dom 缓存。
3. **存储键名**（第 12 章全景表）：改名需迁移脚本。
4. **通知 id 前缀**：`pomodoro-done`、`pomodoro-rest-done`、`task-due-`（SW onClicked 依赖）。
5. **alarm 名**：`pomodoro-phase`、`task-due-check`。
6. **长连接名**：`pomodoro`（SW onConnect 依赖）。
7. **`_devhome_last_mode` 刷新恢复**：页面 beforeunload 写入，boot 读取。
8. **`focus` URL 参数**：自动聚焦「狸猫换太子」依赖。
9. **`data-*` 约定**：菜单动作、设置 action、shortcutSize 等 dataset 契约。

## 13.8 代码量评估

- 页面 JS：40+ 文件，多数 200-500 行（🟡 预警区），`notes/`、`workbench_private/`、`events/` 子模块已按职责拆分（符合「复用性/领域独立性/物理邻近」拆分铁律）。
- `index.html` 1680 行（🔴 红色区）：属 DOM 模板，建议按模板片段拆分。
- `_notes-view.js` / `_quadrant-tasks.js` 等含渲染+逻辑混层，可抽纯函数层。
- 单函数最长集中在番茄钟 `pomodoroPhaseEnd`（~60 行）与 favicon 解析（~110 行），处于黄色预警，可再拆。

## 13.9 结论

项目整体架构清晰（编排入口 + 私有子目录 + 命名空间注入），数据层有三层封装但存在双写冗余，事件系统全面但缺幂等，消息协议简单可靠但无校验。**优先处理 13.1-13.2 的 P0 项（架构与正确性），再按 Roadmap 推进**。每个模块的详细接口与算法见对应章节。
