### 11.1.2 脚本加载顺序（关键）

```
React 层（defer）：
  react.production.min.js → react-dom → ui-components/button.js → dialog.js
  → confirm-dialog.js → dashboard.js → toast.js → prompt-dialog.js
  → tile-form-dialog.js → changelog-dialog.js → shadcn-dialogs.js

第三方库（defer）：lib/marked.min.js → lib/dayjs.min.js

基础设施（defer）：
  secrets → icons → config → logger → storage → storageV2 → dataService
  → fileConfig → state → utils

功能模块（defer）：
  quotes → weather → dailyGreetingCard → proxyManager → favicon → theme-manager
  → bgManager → pageManager → linkOpener → tiles → categoryUI
  → ui/_context-menu → ui/_settings-panel → ui/_tile-editor → ui.js → search
  → tiptap-bundle → notes/_notes-crud → _notes-notebook → _notes-capture
  → _notes-view → _notes-editor → _notes-filter → notes.js → export
  → workbench → workbench_private/_quadrant-tasks → _notes-workbench
  → _pomodoro → _calendar → _dashboard
  → events/category-events → notebook-events → toolbar-events → quadrant-events
  → calendar-events → pomodoro-events → filter-events → settings-events
  → search-events → global-events → misc-events → events.js
  → wallpaper → main.js → matrix-bg.js（最后一个，非 defer）
```

> **加载顺序即依赖顺序**：基础设施 → 功能模块 → 子模块 → 编排入口。`matrix-bg.js` 最后加载且非 defer（可能因 canvas 动画初始化时机）。

## 11.2 `popup.html` — 弹窗页面

**角色**：工具栏图标点击的弹窗。功能相对精简。

### 11.2.1 DOM 结构

```
body
├─ 头部：扩展 logo + 标题 + 版本
├─ 快捷入口区：打开新标签页 / 打开工作台 / 打开侧边栏
├─ 功能开关：快速捕获输入框（或跳转工作台）
├─ 设置入口：打开设置面板（新标签页）
└─ 脚本：popup 专用 js（如有）+ lib
```

> 说明：popup 主要作为入口导航，具体业务在 index.html。若 popup 直连 Native Host 属红线（应经 Background 代理）。

## 11.3 `sidepanel.html` — 侧边栏页面

**角色**：`chrome.sidePanel` 侧边栏。

### 11.3.1 DOM 结构

```
body
├─ 头部：标题 + 关闭/收起
├─ 笔记快捷区：快速捕获 + 最近笔记列表
├─ 番茄钟迷你控件：开始/暂停/状态显示（与 SW 通信）
├─ 任务区：今日任务预览
└─ 脚本：sidepanel.js + 复用基础设施（secrets/icons/config/logger/storage/storageV2/state）
```

**侧边栏打开方式**：页面发 `OPEN_SIDE_PANEL` 消息 → SW `chrome.sidePanel.open({tabId})`。

## 11.4 Shadcn 组件桥接体系

### 11.4.1 构建流程

```
js/components/ui/*.jsx（React 18 + Shadcn 源码，Tailwind class 替换为 CSS 变量）
  → esbuild（npm run build:components）
  → js/ui-components/*.js（全局暴露 window.ShadcnXxx）
```

### 11.4.2 已编译组件

| 编译产物 | 全局 API | 用途 |
|----------|---------|------|
| `button.js` | `window.ShadcnButton` | 按钮 |
| `dialog.js` | `window.ShadcnDialog.{Dialog,DialogOverlay,DialogContent,DialogHeader,DialogTitle,DialogFooter}` | 弹窗 |
| `confirm-dialog.js` | `window.ShadcnConfirmDialog` 等 | 确认框 |
| `prompt-dialog.js` | `window.ShadcnPromptDialog` | 输入框 |
| `tile-form-dialog.js` | `window.ShadcnTileFormDialog` | 磁贴编辑表单 |
| `dashboard.js` | `window.DashboardApp.Dashboard` + `window.__refreshDashboard` | 行为仪表盘 |
| `toast.js` | `window.RTToast` / `window.initReactToast` | 通知（React Toast） |
| `changelog-dialog.js` | `window.ShadcnChangelogDialog` | 更新日志 |

### 11.4.3 使用方式

```html
<script src="js/lib/react.production.min.js"></script>
<script src="js/lib/react-dom.production.min.js"></script>
<script src="js/ui-components/button.js"></script>
```

```js

```

### 11.4.4 `js/shadcn-dialogs.js` — 弹窗封装层

**挂载点**：`ns.shadcnDialogs`（或 ns 级 showConfirm/showPrompt 的实现）

**职责**：将 Shadcn Dialog 封装为项目统一的 Promise API：

| API | 说明 |
|-----|------|
| `ns.showConfirm(message, opts)` → Promise<boolean> | 确认框（title/confirmLabel/danger） |
| `ns.showPrompt(message, opts)` → Promise<string|null> | 输入框 |
| `ns.openChangelog()` | 更新日志弹窗 |
| `ns.openTileFormDialog(tile)` | 磁贴编辑表单弹窗 |

## 11.5 `js/ui/_tile-editor.js` — 磁贴编辑 + 通用弹窗工厂

**挂载点**：`ns.*`

### 11.5.1 磁贴编辑器

- 弹窗表单：名称、URL、图标、颜色、类型。
- 新增/编辑磁贴统一入口。
- 保存后 `tileManager.add/update` + 重渲染。

### 11.5.2 通用弹窗工厂

- 提供 `showConfirm` / `showPrompt` 的**原生 JS 实现**（wb-confirm-overlay/panel 结构），供非 React 场景使用；React 场景走 Shadcn。
- 支持 Enter/Esc/遮罩关闭，样式跟随 Token。

## 11.6 `js/ui/_settings-panel.js` — 设置面板生命周期

**挂载点**：`ns.openSettingsPanel`、`ns.closeSettingsPanel`、`ns.switchSettingsTab`、`ns.syncSettingsControls`、`ns.handleSettingsAction`

### 11.6.1 API

| API | 说明 |
|-----|------|
| `ns.openSettingsPanel()` | 打开（overlay visible） |
| `ns.closeSettingsPanel()` | 关闭 |
| `ns.switchSettingsTab(sTab)` | 切 Tab（日常/工作台/笔记/AI 等） |
| `ns.syncSettingsControls()` | 将存储值同步到所有控件（开面板时调用） |
| `ns.handleSettingsAction(action)` | 按 data-setting-action 分发（toggleAutoFocus/toggleCategoryMemory/toggleStrict/toggleFileSync 等） |
| `ns._syncProxyControls()` | 同步代理检测状态（proxyManager 事件回调） |
| `ns._saveTaskNotifySettings()` / `ns._saveStrictMode()` / `ns._saveFileSync()` | 保存各配置 |

### 11.6.2 Tab 结构（s-nav-item）

日常（快捷方式/布局/图标/字体/动画/背景/壁纸/Matrix）、工作台（任务通知/番茄钟）、笔记（文件同步/严格模式）、AI（供应商/Key）、导出（数据导出）。

## 11.7 `js/ui/_context-menu.js` — 右键菜单

**挂载点**：`ns.showContextMenu`、`ns.showBlankContextMenu`、`ns.handleContextMenuAction`、`ns.handleBlankMenuAction`、`ns.handleSubMenuClick`、`ns.showEditorContextMenu`

| API | 说明 |
|-----|------|
| `ns.showContextMenu(e, tile)` | 磁贴右键：打开/编辑/删除/移动到分类/复制链接等 |
| `ns.showBlankContextMenu(e)` | 空白右键：新建分类/新建磁贴/导入导出/设置/刷新语录等 |
| `ns.handleContextMenuAction(action)` | 磁贴菜单动作分发 |
| `ns.handleBlankMenuAction(action)` | 空白菜单动作分发 |
| `ns.showEditorContextMenu(e)` | 编辑器右键（copy/paste，见 misc） |

## 11.9 重构要点（UI/页面）

1. **index.html 1680 行单文件**：所有 DOM 结构集中，建议拆为模板片段（日常/工作台/弹窗/图标库分离）。
2. **脚本 60+ 个 `<script>` 标签**：加载顺序脆弱，建议打包（bundle 模式已支持）。
3. **Shadcn 与原生弹窗双轨**：showConfirm 有 React 与原生两实现，需统一（推荐原生轻量实现为默认，React 仅重组件）。
4. **`#modalRoot` 单挂载点**：多弹窗并发需队列管理。
5. **popup 业务薄**：作为入口页，可与 sidepanel 逻辑合并。
6. **事件绑定入口 `bindEvents()`**：依赖所有 `_bind*XxxEvents` 存在，缺失即报错（可选链已防，但静默）。
