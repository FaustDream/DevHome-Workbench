# 18 页面数据流详解

> 本文档对每个页面给出**完整数据流**：外部 API 请求/响应格式、内部状态管理、缓存策略、错误处理流程。
> 覆盖：新标签页（index.html）、弹窗（popup.html）、侧边栏（sidepanel.html）、后台 SW。

---

## 18.1 新标签页（index.html）数据流

### 18.1.1 启动数据流（boot 6 Phase）

```
页面加载
  ├─ Phase 0: theme.init()                        // 主题，无 IO
  ├─ Phase 1: storageV2.migrateFromLegacy()        // 数据迁移（幂等）
  │         + fileConfig.init()                    // 文件配置恢复
  │         + proxyManager.init()                  // 代理检测（异步不阻塞）
  ├─ Phase 2: initEngine() + applyShortcutSize/Columns + applyLayoutConfig
  │         + openFaviconDB() + tileManager.load() + renderTiles()   // 首屏（缓存优先）
  ├─ Phase 3: notesManager.load() + loadCaptures() + loadNotebooks()
  │         + CONFIG 读取（lastNotebookId/focusShortcut）            // v2 数据并行加载
  │         + 数据就绪后无条件重渲染磁贴
  ├─ Phase 4: 自动聚焦 + 分类记忆 + applyCategoryButtonMode
  │         + syncSettingsControls + bindEvents()
  ├─ Phase 5: rAF 延迟加载（dailyGreetingCard/weather/taskNotify/React Toast）
  └─ Phase 6: 日志收尾 + 「刷新恢复」+ beforeunload 注册
```

**状态管理**：
- 全局状态集中于 `ns.state`（`js/state.js`）：`notes`、`captures`、`notebooks`、`currentPage`、`pageNames`、`searchHistory`、`currentDevhomeMode`、`currentNote` 等。
- DOM 引用缓存于 `ns.dom`，避免重复 querySelector。
- 启动完成后 `bindEvents()` 一次性绑定全部事件。

**错误处理**：
- Phase 1 迁移失败 → `'no_legacy_data'` 降级，不阻塞。
- Phase 2 磁贴加载失败 → 空态渲染。
- Phase 3 v2 数据失败 → fallback 空数组。
- 文件配置权限过期 → `fileConfig._tryRecoverRead/Write` → `pickDir` 三岔流程，`config-warning-bar` 提示。

### 18.1.2 磁贴数据流

```
数据源：v2/pages（权威）+ tabpage_pages（缓存）
  ├─ 读取：pageManager.load() → normalizePageState（修复名错位）
  │        → tileManager.updateCurrentTiles()（position 排序）→ renderTiles()
  ├─ 写入：tileManager.add/update/remove/reorder/changePage
  │        → save()（position 与下标同步）→ pageManager.save
  │        → 双写 v2/pages + tabpage_pages + backupPagesSnapshot（≤3 份）
  ├─ 错误：写入失败 → 乐观锁重试（3 次）→ toast「数据保存失败」
  └─ 缓存：tabpage_pages 24h TTL；启动先用缓存渲染，数据就绪后重渲染
```

### 18.1.3 搜索数据流

```
用户输入
  ├─ buildSuggestions(q)：历史（包含匹配）+ 磁贴（label 包含）+ Bing 联想
  │    └─ 联想请求：GET https://api.bing.com/osjson.aspx?query=<q>
  │        响应格式：[query, ["suggestion1","suggestion2",...]]
  │        150ms 防抖；失败 console.warn 静默降级（仅本地建议）
  ├─ Enter 执行：openUrl(engine.base + encodeURIComponent(query), {type:'search'})
  │    引擎格式：{id, name, url, iconName|badge|svg}
  └─ 历史：addSearchHistory（去重，≤20 条，写 tabpage_search_history）
```

**缓存策略**：搜索历史无 TTL（持久）；Bing 联想结果不缓存（每次请求）。

### 18.1.4 天气数据流（Open-Meteo）

```
initWeather()
  ├─ getLocation()：Geolocation（5s 超时）→ 失败用北京默认 (39.9042, 116.4074)
  ├─ isCacheValid(lat,lon)：读 tabpage_weather_cache
  │    ├─ TTL 30min 内 + 坐标偏移 <1° → 命中缓存，不请求
  │    └─ 否则 → fetchWeather(lat, lon)
  ├─ GET https://api.open-meteo.com/v1/forecast
  │    ?latitude=..&longitude=..&current=temperature_2m,weather_code
  │    &daily=temperature_2m_max,temperature_2m_min,weather_code
  │    &timezone=auto&forecast_days=3
  ├─ 响应格式：
  │    { current: {temperature_2m, weather_code},
  │      daily: {time[], temperature_2m_max[], temperature_2m_min[], weather_code[]} }
  ├─ WMO 码映射 WEATHER_MAP → 本地 SVG 图标 + 文案
  └─ 写缓存 + 渲染
错误处理：
  - Geolocation 拒绝/超时 → 北京兜底
  - fetch 失败 → toast 错误提示，保留上次缓存
  - 双击天气徽章 → 强制刷新（跳过缓存）
```

### 18.1.5 每日问候卡数据流

```
initDailyGreetingCard()
  ├─ 时段问候：getGreetingByHour(hour)（5-9 早 / 9-12 上午 / 12-14 中 / 14-18 下 / 18-24 晚 / 其他深夜）
  ├─ 鼓励语：读 daily_greeting_card_quote = {date, text}
  │    ├─ date 与今日相同 → 用缓存（每日一句不重复）
  │    └─ 不同 → 从 ENCOURAGE_QUOTES 随机 + 写缓存
  ├─ 昵称：config_nickname（默认「主人」）
  └─ 交互：双击鼓励语 → refreshEncourage() 强制重随机；双击天气 → 刷新天气
```

### 18.1.6 favicon 数据流

```
renderTiles → tile.icon 为空
  ├─ openFaviconDB()：IndexedDB 读缓存
  │    ├─ 命中 → dataURL 直接渲染
  │    └─ 未命中 → chrome.runtime.sendMessage({type:'RESOLVE_FAVICON', domain})
  │          → SW resolveRealFavicon（favicon.ico → 首页<link>解析 → DuckDuckGo 兜底）
  │          → 响应 {success, dataUrl|null} → 写 IndexedDB + 渲染
  └─ 失败（null）→ 回退首字符/内置图标
缓存：IndexedDB 持久缓存（无 TTL），SW 单次解析上限 6s
```

### 18.1.7 番茄钟数据流（页面端）

```
页面 startPomodoro(params)
  ├─ sendMessage(POMODORO_START, params) → SW startPomodoro
  ├─ SW 每秒 broadcastPomodoroState() → 长连接端口 → 页面 POMODORO_STATE 监听
  │    ├─ 有长连接：port.postMessage（页面建立 port.name='pomodoro'）
  │    └─ 无端口：chrome.runtime.sendMessage 单播
  ├─ 页面更新：顶部常驻条 #wbPomodoroTop + 悬浮面板 #wbFloatingPomodoro
  ├─ 阶段结束：SW pomodoroPhaseEnd → 通知 + 广播 → 页面自动进入休息/停止
  └─ 状态持久化：v2/pomodoro_state（SW 唤醒恢复用）
错误处理：
  - 消息无响应（SW 休眠中）→ catch 静默，页面显示待同步状态
  - sendResponse 回调未触发 → Promise 超时 fallback
```

### 18.1.8 笔记/捕获数据流

```
创建笔记：createNote → state.notes.unshift → storageV2.set(v2/notes) → fileConfig.markDirty('notes')
编辑笔记：openNoteEditor → Tiptap onUpdate → _triggerAutoSave(400ms防抖) → saveCurrentNote
  → cleanEmptyHTML → countWords → updateNote → v2/notes
删除笔记：deleteWithUndo（撤销队列）→ v2/notes
快速捕获：addCapture → v2/captures（≤200 条）→ renderCaptures
剪藏：SW clip-capture（右键菜单）→ 写 v2/captures 或 v2/notes
```

### 18.1.9 任务数据流（双写，R2 待收敛）

```
addTask/updateTask → saveWorkbenchState
  ├─ devhome_workbench（localStorage 旧格式）
  └─ storageV2.set(v2/tasks)（扁平带 quadrant）
        → SW checkTaskDueNotifications（15min alarm）→ 通知
```

### 18.1.10 AI 对话数据流

```
aiChat.send(input)
  ├─ generateAI('quick-chat', input)
  │    ├─ 读 v2/config.aiApi（activeProvider + providers）
  │    ├─ getProviderById / createOpenAIProvider（OpenAI 兼容适配器）
  │    ├─ 合并配置（apiKey/endpoint/model）
  │    ├─ 无 apiKey → toast「请先配置 API Key」
  │    └─ 发起请求（流式/非流式）
  ├─ 回复 → sanitizeHtml(marked.parse(reply)) → 渲染气泡
  ├─ 历史持久化：ai_chat_history（chrome.storage.local）
  └─ 保存 → createNote({title:'AI 对话', content:对话HTML})
错误处理：
  - 网络失败 → toast 错误 + 气泡失败态
  - 供应商 401/403 → 提示检查 Key
  - 回复含不可信内容 → DOMPurify 净化（R17）
```

## 18.2 弹窗（popup.html）数据流

```
popup 打开
  ├─ 读取 chrome.storage（轻量：无 v2 全量读取，仅必要配置）
  ├─ 快捷入口：
  │    ├─ 打开新标签页 → chrome.tabs.create({url:'index.html'})
  │    ├─ 打开工作台 → chrome.tabs.create({url:'index.html?focus'})
  │    └─ 打开侧边栏 → sendMessage(OPEN_SIDE_PANEL) → SW chrome.sidePanel.open
  ├─ 快速捕获：Enter → sendMessage 或直接写 v2/captures
  └─ 设置入口 → 打开 index.html 的设置 Tab
错误处理：
  - sidePanel.open 失败（无 tabId）→ catch 提示
  - 捕获写入失败 → toast
```

## 18.3 侧边栏（sidepanel.html）数据流

```
sidepanel 打开
  ├─ 加载基础设施（secrets/icons/config/logger/storage/storageV2/state）——轻量子集
  ├─ 笔记快捷区：
  │    ├─ 快速捕获输入 → addCapture → v2/captures → 刷新最近列表
  │    └─ 最近笔记列表 → 点击 → chrome.tabs.create 打开 index.html 定位到该笔记
  ├─ 番茄钟迷你控件：
  │    ├─ 打开时 GET_STATE 拉取 → 显示状态
  │    ├─ 开始/暂停 → POMODORO_START/PAUSE → SW
  │    └─ 监听广播更新（若建立长连接）
  ├─ 今日任务预览：读 v2/tasks，过滤 active + 今天计划
  │    └─ 空数据 → 「今天还没有计划任务」
  └─ 设置入口
错误处理：
  - v2 数据读取失败 → 空态
  - 番茄钟消息无响应 → 状态显示「待同步」
```

## 18.4 后台 SW 数据流

### 18.4.1 生命周期

```
SW 启动
  ├─ importScripts(bg/_quotes.js, _pomodoro-core.js, _pomodoro-broadcast.js,
  │               _clip-capture.js, _task-notify.js)     // 共享全局作用域
  ├─ onInstalled → 创建右键菜单（selection）
  ├─ onStartup → restorePomodoroState()
  ├─ 启动时 → alarms.create('task-due-check', {periodInMinutes:15})
  ├─ onMessage → 判别联合路由（R3）
  ├─ onConnect → 管理 pomodoro 长连接端口
  ├─ onAlarm → 'pomodoro-phase' → phaseEnd；'task-due-check' → checkTaskDueNotifications
  └─ notifications.onClicked → 聚焦/打开 index.html
```

### 18.4.2 剪藏数据流（右键菜单）

```
用户选中文本 → 右键「剪藏到工作台」→ contextMenus.onClicked
  ├─ 读取 sender.tab + selectionText
  ├─ 构造：title=页面title, content=选区文本, sourceUrl, sourceTitle
  ├─ 写入 v2/captures（或 v2/notes，取决于配置）
  └─ 可选通知「已剪藏」
错误处理：
  - 无选区 → 菜单不显示（contexts:selection 保证）
  - 写入失败 → 通知错误提示
```

### 18.4.3 消息协议错误处理总则（R3/R20）

```
onMessage 收到 unknown msg
  ├─ ExtensionRequest.safeParse(msg)
  │    ├─ 失败 → {success:false, reason:'invalid_message'}
  │    └─ 成功 → switch(type) 分派
  │         ├─ 已知 type 处理
  │         └─ default → {success:false, reason:'unknown_message_type'}
  └─ 处理器内部异常 → try/catch → {success:false, reason:'internal_error'}
```

## 18.5 缓存策略总表

| 数据 | 存储 | TTL | 失效策略 |
|------|------|-----|---------|
| 磁贴页数据 | v2/pages + tabpage_pages | 24h（缓存层） | 写入即更新；启动重渲染 |
| 笔记/捕获/任务/笔记本 | v2/* | 无 | 写入即更新（乐观锁） |
| 搜索历史 | tabpage_search_history | 无（≤20 条） | 手动清除 |
| 天气 | tabpage_weather_cache | 30min | 坐标偏移 <1°；双击强制刷新 |
| 鼓励语 | daily_greeting_card_quote | 每日（按 date 匹配） | 隔日重随机 |
| favicon | IndexedDB | 无 | 永久缓存 |
| 壁纸 | wallpaperImage | 无 | 覆盖上传 |
| 倒计时 | countdowns | 无 | CRUD 更新 |
| 配置 | v2/config + tabpage_* | 无 | 设置面板保存 |
| 文件同步 | devhome-config.json | 无 | storage 写后 3s / v2 写后 1s 防抖 |

## 18.6 错误处理策略总表（R20）

| 场景 | 处理 |
|------|------|
| JSON.parse 失败 | 返回 fallback，不抛错 |
| chrome.storage 不可用 | 降级 localStorage 缓存 |
| 乐观锁重试 3 次失败 | toast「数据保存失败，请刷新页面后重试」 |
| 外部 API 失败（天气/Bing/favicon/AI） | toast 错误 + 保留上次数据 / 静默降级 |
| 文件权限过期 | 恢复授权三岔流程 + warning bar |
| 消息体校验失败 | `{success:false, reason:'invalid_message'}` 拒绝 |
| 剪藏无选区 | 菜单不显示 |
| 番茄钟 alarm 失败 | 降级内存计时 |
| 配额 >90% | checkQuota 告警 + 提示 |
