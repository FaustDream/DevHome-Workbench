# 07 笔记系统

> 本章覆盖完整的笔记子系统：编排入口（notes.js）+ 6 个私有子模块 + Tiptap 富文本编辑器 + Markdown 导出。这是项目中最大、最复杂的子系统。

## 7.1 模块结构

```
js/notes.js                    # 编排入口：定义 namespace、NOTES_TYPE、常量、notesManager
js/notes/_notes-crud.js        # 笔记 CRUD + 数据迁移 + 字数统计
js/notes/_notes-notebook.js    # 笔记本 CRUD 与渲染
js/notes/_notes-capture.js     # 快速捕获 CRUD + 删除撤销队列
js/notes/_notes-view.js        # 笔记列表渲染（筛选/搜索/日期分组）
js/notes/_notes-editor.js      # Tiptap 编辑器生命周期 + 自动保存 + 内容清理
js/notes/_notes-filter.js      # 自定义标签筛选 CRUD + 类型徽章/选择器
js/tiptap-editor.js            # Tiptap 封装（构建为 js/tiptap-bundle.js）
js/export.js                   # Markdown 导出
```

## 7.2 `js/notes.js` — 编排入口

**挂载点**：`ns.notesManager`

**职责**：聚合 6 个子模块，定义常量（`NOTE_TYPES`、`EMPTY_STATE_MESSAGES`、`DEFAULT_V2_CONFIG`），暴露统一的 `notesManager` API。

### 7.2.1 常量

- `ns.NOTE_TYPES`：内置笔记类型映射（note=笔记、idea=想法 等）。
- `ns.EMPTY_STATE_MESSAGES`：`{notes:[...], captures:[...]}` 空状态文案池（随机展示）。
- `ns.DEFAULT_V2_CONFIG`：默认配置（含 `customNoteTypes: []`、`lastNotebookId`、`focusShortcut`、`aiApi`）。

### 7.2.2 notesManager 对外 API（汇总）

| API | 来源 | 说明 |

| `notesManager.saveNotes()` | crud | 保存笔记 |

## 7.3 `js/notes/_notes-crud.js` — 笔记 CRUD 与迁移

**挂载点**：`ns.*`

### 7.3.1 ID 生成

```js
noteId() = 'note_' + Date.now() + '_' + Math.random().toString(36).slice(2, 7)
```

### 7.3.2 字数统计 `ns.countWords`（关键算法）

1. 去除 HTML 标签 → plain 文本。
2. 中文字符数：`plain.match(/[\u4e00-\u9fff\u3400-\u4dbf]/g)`。
3. 英文词数：`plain.match(/[a-zA-Z0-9]+/g)`。
4. 返回 `chinese + words`。

### 7.3.3 数据迁移 `loadNotes`（关键算法）

遍历笔记，迁移：
- 缺 `id` → 补 `note_<ts>_<rand>`。
- 缺 `wordCount` → `countWords(content)` 补齐。
- 缺 `updatedAt` → 用 `createdAt` 或 `Date.now()`。
- `notebookId` undefined → null。
- 存在废弃字段 `doc` → 删除。
- 有迁移 → `saveNotes()` 持久化。

### 7.3.4 创建笔记 `createNote`（关键数据流）

```
now = Date.now()
tags = [dateTag(now)] + data.tags（日期标签置首）
notebookId = data.notebookId ?? (state._notebookFilter || state._lastNotebookId || null)
note = {id, title:'无标题', content:'', wordCount, type:'note', tags,
        sourceUrl:'', sourceTitle:'', status:'active', notebookId, createdAt, updatedAt}
state.notes.unshift(note) → saveNotes() → return note
```

### 7.3.5 日期标签

```js
dateTag(ts) = 'YYYY-MM-DD'
isDateTag(tag)：防御 /^\d{4}-\d{2}-\d{2}$/，tag 长度≤10 且为 string
```

## 7.4 `js/notes/_notes-notebook.js` — 笔记本管理

**挂载点**：`ns.*`

- **ID**：`'nb_' + Date.now() + '_' + rand`。
- **迁移**：`loadNotebooks` 补齐 `order` 字段（`Date.now()+i`），排序。
- **createNotebook(name)**：`{id, name, createdAt, updatedAt, order}`，按 order 排序。
- **renameNotebook(id, newName)**。
- **deleteNotebook(id)**（关键流程）：该笔记本下所有笔记 `notebookId=null` → 删笔记本 → 若当前筛选该笔记本则重置筛选 → toast「已删除，N 条笔记移回未分类」。

## 7.5 `js/notes/_notes-capture.js` — 快速捕获 + 撤销

**挂载点**：`ns.*`

### 7.5.1 快速捕获

```js
captureId() = 'cap_' + Date.now() + '_' + rand
cap = {id, content, doc:null, wordCount:0, tags:[], createdAt, updatedAt}
state.captures.unshift(cap) → storageV2.set(CAPTURES)
```

`renderCaptures()`：最近 5 条，空态随机文案。

### 7.5.2 删除撤销机制（关键算法）

```
deleteWithUndo(item, kind)：
  1. 压入 state._deletedNotes 队列
  2. 执行真实删除（deleteNote/deleteCapture）
  3. 删除后：若当前编辑的正是它 → closeNoteEditor；renderNotesList；renderCaptures；刷新四象限看板
  4. 弹出 showActionToast('已删除"xx"', '撤销', onUndo)
     onUndo：从队列移除 → restoreNote/restoreCapture → 若当前编辑的是它 → openNoteEditor
```

> 注意：`state._deletedNotes` 是内存队列，刷新页面即失效（撤销仅限会话内）。

## 7.6 `js/notes/_notes-view.js` — 笔记列表渲染

**挂载点**：`ns.renderNotesList`

**职责**：笔记+捕获混合列表的筛选、搜索、日期分组渲染。

### 7.6.1 列表组装

1. 收集笔记（`status==='active'`，标记 `_kind:'note'`）+ 捕获（`_kind:'capture'`，标题=content 前 40 字）。
2. 笔记本筛选（`state._notebookFilter`）：仅笔记参与，捕获排除。
3. 类型筛选：`uncategorized`（未分类笔记）/ `all` / 多标签匹配（`type="note,idea"`）。
4. 搜索：标题/内容/标签包含关键字。
5. 按 `updatedAt`/`createdAt` 降序。

### 7.6.2 日期分组（关键算法）

`getDateGroupLabel(dateStr)`：
- 与今天相等 → 「今天」；与昨天相等 → 「昨天」。
- 否则 → 「M月D日 周X」。

`formatRelativeTime(ts)`：刚刚 / N分钟前 / N小时前 / N天前 / M/D。

## 7.7 `js/notes/_notes-editor.js` — Tiptap 编辑器

**挂载点**：`ns.*`

### 7.7.1 `openNoteEditor(note)`（关键流程）

1. `state.currentNote = note`；判定 `isCapture`。
2. 专注模式下确保 `#devhomeStage` visible（避免编辑器在隐藏舞台内不可见）。
3. 切换 UI：隐藏空态 `#wbNotesEditorEmpty`，显示激活 `#wbNotesEditorActive`；捕获隐藏「转任务」wrap。
4. 标题：捕获只读 + 半透明。
5. 渲染类型徽章/笔记本徽章。
6. **Tiptap 创建**：销毁旧实例（防内存泄漏）→ `tiptapEditor.create('#wbNoteContent', content, {editable:!isCapture, onUpdate})`。
   - 捕获内容：`escapeHtml(content).replace(/\n/g,'<br>')`。
   - onUpdate：`_triggerAutoSave()`（400ms 防抖）+ 更新字数。

### 7.7.2 `closeNoteEditor()`（关键流程）

保存当前 → 销毁 Tiptap → `state.currentNote=null` → 显示空态、隐藏激活 → 隐藏转任务 wrap 与象限选择器 → 重渲染列表。

### 7.7.3 `saveCurrentNote()`（关键流程）

- 捕获：`getHTML` → `cleanEmptyHTML` → `updateCapture`。
- 笔记：标题、类型、日期标签保障（无日期标签则补创建日标签）、`getHTML` → `cleanEmptyHTML` → `countWords` → `updateNote`。

### 7.7.4 `cleanEmptyHTML`（关键算法）

清理复制粘贴产生的空段落：
1. 移除 `空<p></p>`。
2. 合并连续 `<br>` 为单个。
3. 移除首尾空段落。
4. 移除仅含 `<br>` 的空段落。
5. 修复任务列表内 `<div><p></p></div>` → `<div></div>`。

## 7.8 `js/notes/_notes-filter.js` — 自定义标签筛选

**挂载点**：`ns.*`

- **自定义类型**（`v2/config.customNoteTypes`）：`[{key, label, icon}]`，渲染为 `.wb-filter-chip.custom[data-filter=key]`。
- **图标兼容**：`renderStoredIcon(icon)`——语义名走 `ns.icon()`，旧 emoji 保留原文。
- **旧输入兼容** `parseIconAndName(input)`：正则 `^(\p{Emoji_Presentation}|\p{Emoji}\uFE0F?)\s*` 解析「emoji 名称」。
- 行内创建自定义标签：无弹窗，直接在标签栏插入输入框（`startInlineCustomFilter`）。
- 类型徽章：`wbNoteTypeBadge` 点击打开 `#wbNoteTypePicker`；多类型切换 `toggleNoteType`；删除 `removeNoteType`。

## 7.9 `js/tiptap-editor.js` — Tiptap 封装

**挂载点**：`ns.tiptapEditor`（构建产物 `js/tiptap-bundle.js`）

### 7.9.1 扩展注册

```js
Editor + StarterKit + Placeholder + TaskList + TaskItem
       + TextAlign + Highlight + TextStyle + Color + FontSize
```

### 7.9.2 API

| API | 说明 |
|-----|------|
| `ns.tiptapEditor.create(selector, content, opts)` | 创建编辑器（opts: id/editable/onUpdate） |
| `ns.tiptapEditor.getHTML(id)` | 获取 HTML |
| `ns.tiptapEditor.getText(id)` | 获取纯文本 |
| `ns.tiptapEditor.setContent(id, html)` | 设置内容 |
| `ns.tiptapEditor.destroy(id)` | 销毁实例 |
| `ns.tiptapEditor.getEditor(id)` | 获取原生 Editor |

### 7.9.3 任务列表剪贴板序列化（关键算法）

- `hasTaskNode(fragment)`：递归检测 taskList/taskItem 节点。
- 仅当复制含任务节点时接管文本序列化：
  - `serializeTaskItemText(node, level, skipCompleted)`：`[x]`/`[ ]` + 标题（跳过嵌套任务列表），嵌套任务加 2 空格缩进。
  - 支持 `hideCompletedActive()`（隐藏已完成）时跳过已完成项。
  - `escapeClipboardHtml`：转义 `&<>"'` 防粘贴破坏。
- 普通段落继续用 Tiptap 默认规则。

## 7.10 `js/export.js` — Markdown 导出

**挂载点**：`ns.renderExportList`、`ns.exportSelected`、`ns.toggleSelectAllExport`

**职责**：选择笔记/捕获/任务 → 拼接 .md → `chrome.downloads.download`。

### 7.10.1 导出列表渲染

按 filter（all/note/capture/task）收集：
- 笔记：`📝` + 标题。
- 捕获：`⚡` + 内容前 50 字。
- 任务：`✅/❌/⬜` + 标题（来自 `state.workbench.quadrants`）。
- 按时间倒序；空态文案。

### 7.10.2 导出流程

```
renderExportList → 勾选 → exportSelected
  → 校验至少选一项
  → 按类型拼接 Markdown（# 标题 + 时间 + 各条目）
  → chrome.downloads.download({url: dataURL 或 blob URL})
```

## 7.11 笔记数据流全景

```
创建：createNote → state.notes.unshift → storageV2.set(v2/notes) → fileConfig.markDirty('notes')
编辑：openNoteEditor → Tiptap onUpdate → _triggerAutoSave(400ms) → saveCurrentNote → updateNote → v2/notes
删除：deleteNote → filter → v2/notes；deleteWithUndo 带撤销 toast
剪藏：SW clip-capture → 笔记面板？/ addCapture → v2/captures
迁移：loadNotes → 字段补齐 → saveNotes
```

## 7.12 重构要点（笔记系统）

1. **`notesManager` API 大而全**（40+ 方法挂 ns），无接口文档与类型约束，建议建立类型化契约。
2. **撤销队列为内存态**：刷新丢失，可评估持久化或接受限制。
3. **Tiptap 实例管理**依赖 `_tiptapInstanceId` 单例，多编辑器并发（未来需求）需重构为注册表。
4. **`cleanEmptyHTML` 正则链**脆弱，建议换 DOM 遍历清理。
5. **笔记与捕获双列表合并**渲染（view 模块）逻辑复杂，可抽纯函数便于测试。
6. **字数统计算法**为启发式（中文每字 1 + 英文每词 1），需明确口径并测试。
