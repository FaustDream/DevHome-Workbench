# 09 事件系统

> 本章覆盖页面端所有 DOM 事件绑定的编排体系：入口（events.js）+ 11 个事件子模块，以及 `bindEvents` 的绑定顺序与职责划分。

## 9.1 模块结构

```
js/events.js                    # 编排入口：bindEvents() 聚合所有 _bind*XxxEvents
js/events/category-events.js    # 分类行：按钮点击、删除、添加、长按拖拽
js/events/notebook-events.js    # 笔记本：下拉、新建、重命名、删除、切换
js/events/toolbar-events.js     # 工具栏：返回日常、清空任务、过滤切换、侧栏折叠、新建笔记/笔记本/标签
js/events/quadrant-events.js    # 四象限：任务卡片点击/删除/完成、编辑、时间设置
js/events/calendar-events.js    # 日历：导航、日期选择、事件点击
js/events/pomodoro-events.js    # 番茄钟：开始/暂停/重置、模式/时长/休息/自动循环、悬浮面板互斥
js/events/filter-events.js      # 筛选：类型/标签/笔记本筛选点击
js/events/settings-events.js    # 设置面板：开关面板、Tab、快捷键录制、任务通知、Matrix、F4-F9
js/events/search-events.js      # 搜索：输入、键盘、引擎选择、建议点击
js/events/global-events.js      # 全局：文档点击关闭、Esc、快捷键、右键菜单、视图缩放
js/events/misc-events.js        # 杂项：磁贴交互、快速捕获、笔记列表、导入、文件配置、自动保存
```

## 9.2 `js/events.js` — 编排入口

**挂载点**：`ns.bindEvents`

**职责**：按依赖顺序调用所有 `_bind*XxxEvents()`，一次性完成全局事件绑定。

```js
ns.bindEvents = function () {
    ns._bindCategoryEvents?.();
    ns._bindNotebookEvents?.();
    ns._bindToolbarEvents?.();
    ns._bindQuadrantEvents?.();
    ns._bindCalendarEvents?.();
    ns._bindPomodoroEvents?.();
    ns._bindFilterEvents?.();
    ns._bindSettingsEvents?.();
    ns._bindSearchEvents?.();
    ns._bindGlobalEvents?.();
    ns._bindMiscEvents?.();
};
```

## 9.3 `events/global-events.js` — 全局事件

**挂载点**：`ns._bindGlobalEvents`

### 9.3.1 文档级点击关闭

- 点击非引擎下拉 → `hideEngineDropdown()`。
- 点击非磁贴/删除按钮 → 退出磁贴编辑模式。
- 点击非分类行 → 退出分类编辑模式。
- 点击非搜索容器 → `hideSuggestions()`。

### 9.3.2 长按定时器清理

- `mouseup`/`touchend` 全局清 `dragLongPressTimer`、`categoryLongPressTimer`。

### 9.3.3 键盘快捷键（关键）

| 按键 | 行为 |
|------|------|
| `/` | 聚焦搜索框 |
| `Ctrl+S`（专注模式） | 拦截（防止默认保存） |
| `Esc` | 退出专注模式 + 关闭下拉/建议/设置面板 + 搜索框 blur |
| 专注快捷键 | `toggleFocusMode()` |
| `Ctrl+I` | 打开 AI 对话（非编辑态） |
| 数字键 1-N | 切换搜索引擎（非编辑态） |
| `Alt+数字 1-5` | 切换搜索引擎 |
| `Ctrl+Plus/Minus` | 视图缩放（`--view-scale`，0.6~1.5，存 `tabpage_view_scale`） |

### 9.3.4 右键菜单

- 磁贴上右键 → `preventDefault` + 显示磁贴菜单。
- 编辑器内容右键（工作台模式）→ 保存选区 `_savedSelection` + 显示编辑器菜单。
- 空白处右键 → `preventDefault` + 空白菜单（除搜索/引擎/弹窗区域）。
- 菜单项点击分发 `handleContextMenuAction(action)` / `handleBlankMenuAction(action)`。
- 分类子菜单 hover/离开延迟隐藏（200ms）。

## 9.4 `events/misc-events.js` — 杂项事件

**挂载点**：`ns._bindMiscEvents`

### 9.4.1 磁贴交互

- 滚轮翻页 `handleWheelScroll`（passive:false，可 preventDefault）。
- 点击删除按钮 `handleTileDeleteClick`；键盘 `handleTileDeleteKeydown`。
- 磁贴链接统一 `openUrl(tileLink.href, {type:'tiles'})`（受新标签设置控制；编辑模式不拦截）。

### 9.4.2 编辑器右键菜单

- `editorContextMenu`：copy/paste 动作（`document.execCommand`）。

### 9.4.3 背景上传

- `bgInput` change → 图片/视频走 `bgManager.upload(file)`，否则 toast 错误。

### 9.4.4 数据导入（关键流程）

```
importInput change → FileReader.readAsText
  → JSON.parse
  → 若有 ns._importBackupData（v3.0 统一导入入口）：
      result==='full' → toast + 1.5s 后 location.reload()
      result==='tiles_only' → tileManager.load + renderTiles + refreshCatRow
      其他 → toast 无效格式
  → 否则（降级旧逻辑）：
      data.pages 为数组 → showConfirm 覆盖确认 → storage.set('pages') + page_names + devhome.workbench → 重新加载渲染
```

### 9.4.5 文件配置目录选择

`configSelectDirBtn` 点击 → `_tryRecoverRead` → `_tryRecoverWrite` → `pickDir` 三岔流程（详见第 02 章 fileConfig）。

### 9.4.6 快速捕获

- `wbCaptureInput` Enter → `addCapture(val)` → `renderCaptures()` + 清空。

### 9.4.7 笔记列表事件

- 删除按钮：`deleteWithUndo(item, delKind)`。
- 点击条目：`openNoteEditor(target)`（kind 判定 note/capture）。

### 9.4.8 笔记转任务

`wbNoteToTaskBtn` → 象限选择器 → 时间选择器（`_readTimePickerValue` 拼 `YYYY-MM-DDTHH:mm:00`）→ `convertNoteToTask(id, quadrant, plannedAt)`。

### 9.4.9 笔记本/类型徽章

- 笔记本徽章点击 → 悬浮选择面板（`.wb-notebook-pick-item`），点击切换 `currentNote.notebookId` + `_triggerAutoSave`。
- 类型徽章点击 → 打开类型选择器 `#wbNoteTypePicker`；chip 删除；badge-add。

### 9.4.10 自动保存（防抖，关键）

```js
ns._triggerAutoSave = function () {
    if (noteAutoSaveTimer) clearTimeout(noteAutoSaveTimer);
    noteAutoSaveTimer = setTimeout(function () {
        if (state.currentNote) ns.saveCurrentNote().then(renderNotesList);
    }, 400);
};
// 标题 input：800ms 防抖
```

- `wbTaskFilterBtn` → `toggleQuadrantFilter`。

## 9.6 `events/settings-events.js` — 设置面板事件

### 9.6.1 开关面板

- `settingsGearBtn` / `devhomeSettingsBtn` → `openSettingsPanel`。
- `settingsCloseBtn` / 遮罩点击 / Esc → `closeSettingsPanel`。
- `changelogBtn` → `openChangelog`。

### 9.6.2 面板内事件委托

- `.s-nav-item[data-sTab]` → `switchSettingsTab`。
- `.s-seg-btn[data-shortcutSize/Columns]` → `applyShortcutSize/Columns` + 同步控件。
- `.s-theme-card[data-scheme]` → `theme.setScheme`。
- `[data-setting-action]` → `handleSettingsAction(action)`。
- `[data-export-filter]` → `setExportFilter`。

### 9.6.3 面板 change 事件

| 控件 | 行为 |
|------|------|
| `remindBeforeSelect` / `taskNotifyToggle` | `_saveTaskNotifySettings` |
| `matrixRainToggle` | start/stop Matrix + 显示/隐藏参数区 |
| `sToggleAutoFocus` | `handleSettingsAction('toggleAutoFocus')` |
| `sToggleCategoryMemory` | 同上 categoryMemory |
| `sToggleNewTabTiles` | 写 `linkNewTab_tiles` |
| `sToggleNewTabSearch` | 写 `linkNewTab_search` |

- `_bindShortcutRecorder`：快捷键录制（专注模式 Ctrl+K 等）。
- `_bindShortcutSave`、`_bindExportSettings`、`_bindToggleSettings`（严格/文件同步）、`_bindMatrixParams`、`_bindWallpaperSliders`、`_bindSearchSettings`、`_bindLayoutSettings`（F5）、`_bindViewScale`（F4）、`_bindTileSettings`、`_bindFontSettings`（F8）、`_bindAnimationSettings`（F9）。

## 9.8 重构要点（事件系统）

1. **事件绑定无幂等保护**：`bindEvents()` 重复调用会重复绑定（仅个别按钮有 `_nbEventBound` 防抖）。建议统一「已绑定标记」或事件委托。
2. **大量 document 级监听**（global/misc/pomodoro 都加 document click/keydown）：需防重复注册累积（ai-chat 已示范 `documentClickHandler` 管理）。
3. **execCommand（copy/paste）已废弃**：编辑器右键菜单应迁移 Clipboard API。
4. **快捷键集中度**：global-events 已集中大部分，但缩放/搜索建议等仍散落，可整理为快捷键注册表。
5. **`_bindEditorContextMenu` 等私有函数**散落 misc，可并入 ui 子模块。
