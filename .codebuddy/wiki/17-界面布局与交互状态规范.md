# 17 界面布局与交互状态规范

> 本文档精确描述三大页面（`index.html` 新标签页 / `popup.html` 弹窗 / `sidepanel.html` 侧边栏）的布局规格：组件位置、间距、对齐、响应式断点与全部交互状态（hover/active/disabled/loading/空数据/错误）。
> 所有间距/圆角/字号/色值均引用 CSS Token（见 `css/base.css` 与 `css/themes/default.css`），禁止硬编码。

## 17.2 响应式断点（css/base.css 断点系统）

| 断点 | 范围 | 布局策略 |
|------|------|---------|
| 移动端 | < 640px | 堆叠布局：`.container` 内边距缩至 `16px 12px`；`.cat-row` 允许换行 `gap:4px`；搜索 `max-width:100%`；磁贴 gap 10px |
| 平板 | 640-1023px | 适度缩减：`.container` `24px 20px`；磁贴 gap 14px |
| 标准桌面（基准） | 1024-1439px | 默认布局，无覆写 |
| 宽屏/2K+ | ≥ 1440px | 内容增密：`.container` `max-width:1280px` 居中；磁贴 gap 20px |

**磁贴网格独立断点**（css/tiles.css）：
- ≤ 768px：`repeat(4, var(--shortcut-container))`
- ≤ 480px：`repeat(3, ...)`，gap 缩至 0.75×（适配手机）
- 默认：`repeat(var(--shortcut-columns), var(--shortcut-container))`，列数由 JS `applyShortcutColumns` 控制（auto/3-8）

### 17.3.2 磁贴网格精确规格

| 属性 | 值 | 说明 |
|------|-----|------|

## 17.8 主题与响应式联动

- **主题切换**：`[data-color-scheme="dark"]` 覆盖全部 Semantic Token（见 17.1 与 themes/default.css），组件无需感知深浅色——**任何组件样式不得硬编码色值**，必须引用 `var(--color-*)`。
- **F4 视图缩放**：`--view-scale`（0.6-1.5），作用于 `.tiles-container` / `.cat-row`（`transform:scale(var(--view-scale))`，origin top center），不触发重排。
- **F5 布局**：`--shortcut-row-gap` / `--shortcut-max-rows` / `--shortcut-rows-mode` 控制磁贴行布局。
- **F6 图标**：`--tile-label-display` / `--tile-icon-shadow` / `--tile-radius-override` / `--tile-opacity`。
- **F8 字体**：`--text-shadow-strength` / `--font-size-multiplier` / `--font-color-override`。
- **F9 动画**：`--animation-speed-multiplier`。

## 17.9 布局实现约束（编码红线）

1. **禁止硬编码色值/间距/圆角**：一律引用 Token（R14 魔法值规则延伸到 CSS）。
2. **hover/active/disabled/loading/空数据/错误**六态必须定义，缺一不可。
3. **新增组件**必须按 17.1 Token 体系设计，遵循 `ui-` 前缀（`.ui-btn`/`.ui-input`/`.ui-dialog`/`.ui-toast`），状态用 `is-` 修饰（`.is-active`/`.is-loading`）。
4. **响应式**：新布局默认以 1024px+ 为基准，再渐进补移动端断点。
5. **禁止 `position:fixed` 滥用**：仅限 `#devhomeStage`、悬浮侧栏/面板、遮罩、toast、context-menu 等全局元素。
