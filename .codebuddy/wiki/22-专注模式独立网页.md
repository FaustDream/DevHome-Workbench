# 22 专注模式独立网页（Web 版改造方案）

> 目标：将 Chrome 扩展内的「专注模式（工作台）」独立为**不依赖插件、可部署到任意静态服务器/本地直接打开**的纯前端网页。
> 撰写时间：2026-08-07 | 状态：进行中

## 22.1 定位与背景

原专注模式（wiki/06）作为新标签页扩展的一部分，依赖：
- `chrome.storage`（数据持久化）
- `chrome.runtime` 长连接 + 消息（番茄钟 SW）
- 扩展页面上下文（`chrome-extension://`）

独立网页版目标：
- 纯静态资源，**无需后端服务**
- 浏览器直接访问（file:// 或任意静态服务器）
- 数据存 `localStorage` + 提供 **JSON 导出/导入备份**
- 保留：四象限任务 / 番茄钟 / 日历 / 笔记 / 主题

## 22.2 部署形态决策（纯前端可行）

| 维度 | 独立网页版 |
|------|-----------|
| 部署 | 静态文件（`workbench.html` + `dist/workbench.js` + css + fonts）|
| 协议 | 无需服务器逻辑，任意 http 静态托管或本地打开 |
| 数据 | localStorage（本机），导出 JSON 备份 |
| 多端 | ❌ 不支持自动同步（需要后端时才支持）|

**何时需要后端**（本项目不启用）：
- 多设备同步 / 多用户账号
- 服务器端 AI / 定时推送 / 文件处理
- 公共部署需数据隔离

## 22.3 架构

```
workbench.html                     # 独立入口（含完整工作台 DOM + sprite）
  └─ dist/workbench.js             # 独立 bundle（standalone 入口）
       ├─ src/pages/workbench/*    # 四象限/番茄钟/日历/笔记/模式（复用）
       ├─ src/pages/workbench/storage.ts   # 环境感知存储（localStorage / chromeStorageV2）
       ├─ src/pages/workbench/standalone-main.ts  # 独立 boot
       └─ css/ + fonts/            # 原扩展样式资源（静态拷贝）
```

**存储适配**：workbench 模块通过 `workbench/storage.ts` 统一访问数据，环境检测：
- 扩展环境（`chrome.runtime` 存在）→ 使用 `chromeStorageV2`（与日常模式共享 v2 数据）
- 独立网页 → 使用 `localStorage`（键直接存，无 v2/ 前缀）

**番茄钟适配**：独立网页无 SW → 纯前端计时（`setInterval` + 时间戳），去掉长连接/消息。

## 22.4 数据模型（localStorage 键）

| 键 | 内容 |
|----|------|
| `tasks` | 四象限任务数组（QuadrantTask[]）|
| `notes` | 笔记数组（NoteItem[]）|
| `pomodoro_sessions` | 番茄钟会话记录 |
| `wb_theme` | 主题 scheme（light/dark/auto）|
| `wb_last_mode` | 恢复上次模式（可选）|

## 22.5 导出 / 导入

- 导出：`workbench.html` 顶栏「导出数据」→ 下载 JSON（含 tasks/notes/pomodoro_sessions）
- 导入：选择 JSON 文件 → 覆盖写回 localStorage
- 复用 `src/pages/index/export.ts` 的逻辑（去 chrome 依赖）

## 22.6 构建

`build.mjs` 新增：
- entry：`src/pages/workbench/standalone-main.ts` → `dist/workbench.js`
- 拷贝 `workbench.html` → `dist/`
- 静态资源（css/fonts/icons）已统一拷贝

## 22.7 与扩展版关系

- 扩展版专注模式**保留**（数据走 v2/chrome.storage，多端一致）
- 独立网页版是**同构功能的不同载体**，数据独立（本机 localStorage）
- 代码复用：四象限/日历/笔记/番茄钟 UI 逻辑共享，仅存储与 SW 层差异

## 22.8 后续可扩展（需后端时）

- 增加 `sync.ts`：localStorage → 远端 API 双向同步
- 用户登录（可选）
