# 04 新标签页核心功能（磁贴/分类/搜索/导航）

> 本章覆盖日常模式下新标签页的核心：磁贴系统（tiles）、分页管理（pageManager）、分类 UI（categoryUI）、搜索（search）、链接打开（linkOpener）、导航（navigation）。

## 4.1 `js/tiles.js` — 磁贴管理

**挂载点**：`ns.tileManager`

**职责**：磁贴数据的 CRUD、页面切换、渲染与拖拽重排。

### 4.1.1 数据结构

**页面**（`tabpage_pages` / `v2/pages`）：

```js
[{ name: '第1页', tiles: [tile, ...] }, ...]
```

**磁贴（tile）**：

```js
{
  id: 'tile_<ts>_<rand>',
  label: '名称',
  url: 'https://...',
  type: 'favicon' | 'custom' | 'text' | 'emoji' | ...,
  icon: '',            // 图标 URL / emoji / SVG
  color: '#4a9eff',    // 底色
  position: 0,         // 排序位
  imageData: ''        // 自定义图标 base64
}
```

### 4.1.2 API 清单

| API | 说明 |
|-----|------|
| `tileManager.load()` → Promise | 从 pageManager 加载页数据，更新 currentTiles |
| `tileManager.updateCurrentTiles()` | 用当前页数据刷新 currentTiles，并按 position 排序 |
| `tileManager.save()` | 保存：写回 position 与数组下标一致 → pageManager.updateCurrentPage → pageManager.save |
| `tileManager.add(tile)` | 新增磁贴（分配 id + position=length） |
| `tileManager.remove(tileId)` | 删除磁贴 |
| `tileManager.update(tileId, updates)` | 更新磁贴属性 |
| `tileManager.reorder(fromIndex, toIndex)` | 拖拽重排 |
| `tileManager.changePage(pageIndex)` | 切页（支持分类记忆写 last_page） |
| `tileManager.addNewPage()` | 新增空白页 |
| `tileManager.removeCurrentPage()` | 删除当前页（moveToCommon 策略） |
| `tileManager.removePageAt(pageIndex, strategy)` | 删除指定页（strategy: moveToCommon） |
| `tileManager.reorderPage(fromIndex, toIndex)` | 页面重排 |
| `tileManager.renameCurrentPage(newName)` | 重命名当前页 |
| `ns.renderTiles()` | 将 currentTiles 渲染为 DOM 磁贴 |
| `ns.handleTileDeleteClick` / `ns.handleTileDeleteKeydown` | 删除按钮点击/键盘处理 |
| `ns.isTileDeleteModeActive()` | 是否处于删除模式 |
| `ns.openUrl(url, opts)` | 统一打开链接（受新标签设置控制） |

### 4.1.3 渲染关键点

- 磁贴 DOM 结构：`<a class="tile" href data-id data-position>` 内嵌图标区 + 标签区。
- 图标渲染优先级：`tile.imageData`（自定义 base64）> `tile.type==='favicon'`（favicon 库/加载）> 内置 icon > 首字符。
- 删除模式：`tileEditMode` 开启时每个磁贴右上角显示删除按钮。

### 4.1.4 拖拽重排（关键算法）

- 支持鼠标与触屏；鼠标 `mousedown→mousemove→mouseup`，触屏 `touchstart` 后用 `dragLongPressTimer`（`TILE_LONG_PRESS_MS=600ms`）判定长按进入拖拽。
- 拖拽中高亮目标位，松手 `reorder(from, to)` 后 `save()`。
- `mouseup`/`touchend` 全局清长按定时器。

## 4.2 `js/pageManager.js` — 分页管理

**挂载点**：`ns.pageManager`

**职责**：磁贴页面数据的加载、增删改、重排与持久化。

| API | 说明 |
|-----|------|
| `pageManager.load()` → Promise | 读取页数据 + 页名，归一化（normalizePageState）并持久化修复结果 |
| `pageManager.getCurrentPageData(pagesData)` | 取当前页（含总页数同步到 state） |
| `pageManager.updateCurrentPage(pagesData, tiles)` | 写回当前页 tiles |
| `pageManager.save(pagesData)` | 持久化（tabpage_pages + v2/pages） |
| `pageManager.addPage(pagesData)` | 追加新页 |
| `pageManager.removePageWithStrategy(pagesData, idx, strategy)` | 删页（moveToCommon 把磁贴并入公共逻辑） |
| `pageManager.reorderPage(pagesData, from, to)` | 页面重排 |
| `pageManager.renamePage(idx, name)` | 重命名 |

**数据流向**：`load()` → `normalizePageState`（修复名错位）→ 若 changed 则持久化 → 写入 `state.pageNames` / `state.totalPages`。

## 4.3 `js/categoryUI.js` — 分类 UI

**挂载点**：`ns.*`（renderCatRow 内部、applyCategoryButtonMode、changePageWithAnimation、handleWheelScroll、分类拖拽）

**职责**：分类按钮行渲染、悬浮弹窗、页面切换动画、滚轮翻页、分类拖拽重排。

### 4.3.1 关键 API

| API | 说明 |
|-----|------|
| `ns.applyCategoryButtonMode(enabled, save)` | 开关分类按钮行，持久化 `cat_row`，渲染按钮 |
| `ns.refreshCatRowIfVisible()` | 重渲染分类行 |
| `ns.changePageWithAnimation(newPage, t0, targetName)` | 带动画切页（含越界/重复保护、分类记忆） |
| `ns.handleWheelScroll(e)` | 滚轮翻页（累加器 + 冷却，阈值 25、冷却 350ms） |
| 分类子菜单 | 右键菜单「移动到分类」二级菜单 |

### 4.3.2 滚轮翻页算法

- `wheelAccumulator` 累加 deltaY；方向反转时清零。
- 累加绝对值 > 25 触发翻页；350ms 冷却（`WHEEL_COOLDOWN`）防止连翻。
- `pageTransition` 状态阻止并发切换。

### 4.3.3 分类行 DOM

```html
<div id="catRow">
  <button class="cat-btn active" data-page="0"><span>第1页</span>
    <span class="cat-delete-btn" data-cat-delete="0">×</span></button>
  ...
  <button class="cat-add-btn" data-cat-add="true">+</button>
</div>
```

### 4.3.4 分类拖拽重排

- 分类按钮长按（`categoryLongPressTimer`）进入拖拽模式，松手调用 `reorderPage`。

## 4.4 `js/search.js` — 搜索系统

**挂载点**：`ns.*`（loadSearchHistory、addSearchHistory、buildSuggestions、renderSuggestions、setEngine、hideSuggestions 等）

**职责**：本地搜索历史 + 磁贴匹配 + Bing API 网络联想词；搜索引擎切换；搜索执行。

### 4.4.1 搜索历史

- 存储：`tabpage_search_history`（`ns.state.searchHistory`），上限 20 条。
- `addSearchHistory(term)`：去重后 unshift，超 20 截断。

### 4.4.2 建议构建（buildSuggestions）

1. 有输入 q：匹配历史（包含 q）+ 磁贴（`tile.label` 包含 q → `{type:'tile', text:url, ...}`）。
2. 无输入：最近 10 条历史。
3. 若开启建议（`getSearchConfig().showSuggestions`）：150ms 防抖后请求 Bing `https://api.bing.com/osjson.aspx?query=...`，合并在线词（去重，type:'online'）。
4. 网络失败仅 console.warn 不抛错。

### 4.4.3 建议面板 DOM

```html
<div class="search-suggestions visible">
  <div class="suggestions-header"><span>搜索建议</span><button class="suggestions-clear-btn">清除历史</button></div>
  <div class="suggestions-list"><div class="suggestion-item ...">...</div></div>
  <div class="suggestions-footer"></div>
</div>
```

- 键盘导航：上下方向键移动 `selectedSuggestionIndex`，Enter 选择，Esc 关闭。
- 点击空白关闭（global-events）。

### 4.4.4 搜索引擎

- `ns.engines`：内置多个引擎（Google/Bing/Baidu/知乎/微博/DuckDuckGo/GitHub 等，见 navigation.js 或 config）。
- 每个引擎：`{ id, name, url, iconName|badge|svg, base }`。
- `ns.setEngine(id)`：持久化 `tabpage_engine`，更新 UI。
- 数字键 1-N 快速切换（global-events），Alt+数字亦可。
- `ns.initEngine()`：启动时恢复引擎选择。

### 4.4.5 执行搜索

- 搜索框 Enter → `openUrl(engine.base + encodeURIComponent(query), {type:'search'})`。
- 搜索结果是否新标签打开受 `linkNewTab_search` 设置控制。

## 4.5 `js/linkOpener.js` — 链接打开统一入口

**挂载点**：`ns.openUrl`

**职责**：统一所有外链打开行为，遵守「新标签打开」设置。

| API | 说明 |
|-----|------|
| `ns.openUrl(url, opts)` | `opts.type`: 'tiles'|'search'|其他；读取 `linkNewTab_<type>` 决定 `chrome.tabs.create` 或 `location.href` |

**关键**：磁贴点击统一走 `openUrl`，实现「磁贴在新标签打开」开关。

## 4.6 `js/navigation.js` — 导航与引擎

**挂载点**：`ns.engines`、`ns.*`

**职责**：搜索引擎定义、引擎下拉 UI、引擎选择交互。

- 引擎下拉：`engine-selector` 按钮 + `engine-dropdown` 面板。
- 下拉渲染每个引擎项（图标 + 名称 + 当前选中高亮）。
- `hideEngineDropdown()`：点击外部/ Esc 关闭。

## 4.7 首屏渲染流程（Phase 2）

```
boot Phase 2
  ├─ initEngine()         恢复引擎
  ├─ applyShortcutSize()  快捷方式尺寸
  ├─ applyShortcutColumns() 列数
  ├─ applyLayoutConfig()  F5 布局
  ├─ openFaviconDB()      打开 IndexedDB
  ├─ tileManager.load()   加载磁贴（Promise）
  ├─ loadSearchHistory()  加载搜索历史
  └─ renderTiles()        先用缓存数据渲染

数据就绪后：tileManager.updateCurrentTiles() → renderTiles() 无条件重渲染
```

## 4.8 重构要点

1. **渲染是「全量 innerHTML 重建」**：`renderTiles` / `renderCatRow` 每次全量重建 DOM，磁贴多时性能差，建议改为局部 diff 或虚拟滚动。
2. **`tileManager` 与 `pageManager` 职责有重叠**：save 的「position 与下标同步」逻辑脆落。
3. **引擎配置与搜索逻辑分散**在 navigation/search 多文件，可合并为单一「搜索引擎注册表」。
4. **滚轮翻页魔法值**（25/350）已具名但局部定义，建议入 config。
5. **`openUrl` 是新标签开关的唯一入口**：新增链接类型需同步注册。
