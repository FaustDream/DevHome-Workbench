# 05 视觉体系与外部服务

> 本章覆盖日常模式的视觉层（主题、背景、壁纸、Matrix、倒计时）与外部数据服务（语录、天气、问候卡片、favicon 解析、代理检测）。

## 5.1 CSS Token 体系

### 5.1.1 CSS 加载分层（重要）

```
fonts.css（字体） → base.css（结构令牌+断点） → tokens.css（语义声明）
  → 各模块 css（tiles/time-search/workbench*/ai-chat...）
  → themes/default.css（Primitive→Semantic 映射 + 深色覆盖，最后加载）
```

### 5.1.2 Token 命名（css/tokens.css）

- 语义 Token 以 `--color-*`、`--spacing-*`、`--radius-*`、`--shadow-*` 命名。
- 关键色 Token：`--color-bg`（背景）、`--color-text` / `--color-text-secondary` / `--color-text-tertiary`（文字三级）、`--color-accent`（主色，Ant Design 蓝 `#1677ff`）、`--color-border` / `--color-border-active`、`--color-danger`、`--color-input-bg` / `--color-input-border`、`--color-bg-elevated`（弹窗/卡片）、`--color-bg-secondary`、`--color-text-inverse`。
- 圆角：8/12/20/28px 四级（`--radius-*`）。
- 阴影：三级 `--shadow-sm/md/lg`。
- 毛玻璃：`backdrop-filter` 相关 Token。

### 5.1.3 深色主题（css/themes/default.css）

- `[data-color-scheme="dark"]` 选择器覆盖 Primitive→Semantic 映射。
- 主题切换由 theme-manager 设置 `data-color-scheme` 属性。

### 5.1.4 Shadcn 桥接（css/tailwind-base.css）

将 Shadcn 组件所需变量映射到项目 Token：

| Shadcn Token | 项目变量 |
|--------------|---------|
| `--background` | `--color-bg` |
| `--foreground` | `--color-text` |
| `--card` | `--color-bg-elevated` |
| `--primary` | `--color-accent` |
| `--secondary` | `--color-bg-secondary` |
| `--destructive` | `--color-danger` |
| `--border` | `--color-border` |
| `--input` | `--color-input-bg` |
| `--ring` | `--color-accent` |

## 5.2 `js/theme-manager.js` — 主题管理

**挂载点**：`ns.theme`

**职责**：主题方案（scheme）的读取、应用、持久化与设置面板联动。

| API | 说明 |
|-----|------|
| `ns.theme.init()` | 启动初始化：读取持久化 scheme 并应用 |
| `ns.theme.setScheme(scheme)` | 切换 scheme（light/dark/auto），持久化，设置 `data-color-scheme` |
| `ns.theme.getScheme()` | 读取当前 scheme |

**scheme 值**：`'light'` / `'dark'` / `'auto'`（跟随系统 prefers-color-scheme）。设置面板有主题卡片（`.s-theme-card[data-scheme]`）点击切换。

## 5.3 `js/bgManager.js` — 背景管理

**挂载点**：`ns.bgManager`

**职责**：新标签页背景图/视频的设置与管理（包括自定义上传）。

| API | 说明 |
|-----|------|
| `bgManager.upload(file)` | 上传图片/视频作为背景 |
| `bgManager.apply(bg)` / `bgManager.remove()` | 应用/移除背景 |
| `bgManager.getState()` | 获取当前背景状态 |

**背景 DOM**：`#bgImage`（图片）、`#bgOverlay`（遮罩）、`#bgVideo`（视频）。

**数据流向**：背景图片数据存入 localStorage（可能 base64），`bgImage.src` 指向数据；遮罩透明度由 `--bg-overlay` CSS 变量控制。

## 5.4 `js/wallpaper.js` — 壁纸功能

**挂载点**：`ns.initWallpaper`、`ns.getCountdowns` 等

**职责**：左下角壁纸按钮 → 控制面板（上传壁纸 + 模糊度 + 遮罩度 + 重置）。

### 5.4.1 存储键

| 键 | 内容 |
|----|------|
| `localStorage('wallpaperImage')` | Base64 压缩后的壁纸图片 |
| `localStorage('wallpaperSettings')` | `{blur, overlay}` 默认 `{blur:0, overlay:30}` |

### 5.4.2 API

| API | 说明 |
|-----|------|
| `ns.initWallpaper()` | 绑定事件 + 加载已保存设置 |
| `ns.getCountdowns()` 等（倒计时无关，见 5.7） | — |

### 5.4.3 图片压缩算法（关键）

1. 读取文件 → FileReader → dataURL。
2. `compressImage`：若图片宽 ≤ 1920 不压缩；否则按比例缩放到宽 1920（Canvas drawImage）。
3. `canvas.toDataURL('image/jpeg', 0.85)` 二次压缩。
4. 写入 localStorage；若超配额（QuotaExceededError）→ toast「壁纸图片过大」。

**模糊/遮罩应用**：`--bg-blur` CSS 变量（`blur(var(--bg-blur))`）+ `bgOverlay.style.opacity = overlay/100`。

## 5.6 `js/countdown.js` — 倒计时卡片

**挂载点**：`ns.initCountdown`、`ns.getCountdowns`、`ns.saveCountdowns`、`ns.calcCountdown`、`ns.showAddCountdown`、`ns.deleteCountdown`

**职责**：目标日期倒计时卡片（剩余天数 + 进度条）。

### 5.6.1 存储

`localStorage('countdowns')`：`[{id:'cd_<ts>', title, targetDate:'YYYY-MM-DD', createdAt:'YYYY-MM-DD'}]`

### 5.6.2 关键算法：`calcCountdown(targetDate, createdAt)`

```
diff = target(00:00) - now
days = Math.ceil(diff / 86400000)
progress = 创建日→目标日的已过比例（0~100%，clamp）
isOverdue = diff < 0
```

- 过期：显示「已过期」红标 + 警告日期徽章。
- 未过期：剩余天数 + 「天后/就在今天！」 + 进度条。
- 每分钟 `setInterval(refreshCountdownUI, 60000)` 刷新。

### 5.6.3 添加流程

`ns.showAddCountdown`：动态构建 `wb-confirm-overlay/panel` 表单（标题+日期），Enter 确认，Esc 关闭，遮罩点击关闭。

## 5.7 `js/quotes.js` — 激励语录（页面端）

**挂载点**：`ns.quotes`（页面端语录库，区别于 bg/_quotes.js 番茄钟语录）

**职责**：提供页面展示的激励语句（如工作台空状态、问候卡片等）。注意与 `bg/_quotes.js`（番茄钟完成/休息语录）是两套独立语料。

## 5.8 `js/weather.js` — 天气预报

**挂载点**：`ns.initWeather`、`ns.refreshWeather` 等

**职责**：使用 Open-Meteo 免费 API（无需 Key），Geolocation 定位，降级北京坐标。不自动请求，手动点击刷新（或缓存过期自动刷新）。

### 5.8.1 常量

```
LAT=39.9042 LON=116.4074（北京默认）
CACHE_TTL = 30min
AUTO_REFRESH_INTERVAL = 30min
```

### 5.8.2 关键流程

1. `getLocation()`：Geolocation 定位（5s 超时），失败用北京。
2. `isCacheValid(lat, lon)`：读 `tabpage_weather_cache`，TTL 内 + 坐标偏移 <1 度视为有效。
3. `fetchWeather(lat, lon)`：GET `https://api.open-meteo.com/v1/forecast?latitude=..&longitude=..&current=temperature_2m,weather_code&daily=temperature_2m_max,temperature_2m_min,weather_code&timezone=auto&forecast_days=3`。
4. WMO 天气码映射 `WEATHER_MAP`：`{0:'晴',1:'大部晴',2:'多云',3:'阴',45/48:'雾',51/53/55:'小雨/中雨/大雨',61/63/65:'小雨/中雨/大雨',71/73:'小雪/中雪',75:'大雪',80/81/82:'阵雨/暴雨/大暴雨',95/96/99:'雷暴/冰雹雷暴'}`，每码对应本地 SVG 图标语义名（weather-sun 等）。
5. 缓存写回 + 渲染（温度、天气文案、图标）。
6. 双击天气徽章手动刷新（dailyGreetingCard 交互）。

## 5.9 `js/dailyGreetingCard.js` — 每日问候区域

**挂载点**：`ns.initDailyGreetingCard`

**职责**：日期 + 天气 + 时段问候 + 鼓励话语，无缝融合纯色背景（无卡片容器）。双击天气刷新天气，双击鼓励语刷新内容。

### 5.9.1 关键逻辑

- **鼓励语料库** `ENCOURAGE_QUOTES`（20 条）。
- **昵称**：`localStorage('config_nickname')`，默认「主人」。
- **时段问候** `getGreetingByHour(hour)`：5-9 早上好 / 9-12 上午好 / 12-14 中午好 / 14-18 下午好 / 18-24 晚上好 / 其他 夜深了。
- **每日随机缓存**：`localStorage('daily_greeting_card_quote') = {date:'YYYY/M/D', text}`，当日不变，隔日重随机；`refreshEncourage()` 强制重随机。
- 天气图标复用 `WEATHER_ICON_MAP`（与 weather.js 一致）。

## 5.10 `js/favicon.js` — favicon 解析

**挂载点**：`ns.loadFavicon`、`ns.openFaviconDB`、`ns.resolveFavicon`（SW 侧）

**职责**：为磁贴加载站点 favicon。策略：

1. 优先从 IndexedDB favicon 缓存读取（避免重复请求）。
2. 未命中 → 发 `RESOLVE_FAVICON` 消息给 SW。
3. SW `resolveRealFavicon(domain)` 解析（见第 10 章）→ 返回 dataURL → 写缓存 + 渲染。

## 5.11 `js/proxyManager.js` — 代理/可达性检测

**挂载点**：`ns.proxyManager`

**职责**：检测 Google 等外站可达性，判断是否需要代理，联动设置面板。

| API | 说明 |
|-----|------|
| `proxyManager.init()` | 初始化：注册事件 + 首次检测 |
| `proxyManager.on(event, cb)` | 事件监听（`googleReachabilityChanged` 等） |
| `proxyManager.check()` | 发起可达性检测 |

**事件**：`googleReachabilityChanged` → boot 中绑定回调自动同步设置面板（`_syncProxyControls`）。依赖 `secrets.js` 中的密钥配置。

## 5.12 重构要点（视觉/外部服务）

1. **两个天气 WMO 映射表重复**（weather.js 与 dailyGreetingCard.js 各一份），应合并为共享模块。
2. **wallpaper 与 bgManager 功能重叠**：壁纸是「背景图 + 模糊/遮罩」，bgManager 是「背景上传」；建议统一为单一背景子系统。
3. **倒计时/壁纸用原生 localStorage 裸键**，未走 `ns.storage` 前缀体系，应迁移。
4. **CSS Token 已健全**，但个别模块 css 仍有硬编码色值，需巡检。
5. **`matrixRain` canvas 高频渲染**：AGENTS.md 要求 rAF 回调禁止打日志（已遵守），但性能参数需可调。
