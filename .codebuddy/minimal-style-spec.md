# Thrilled · 极简冷调设计规范（Minimal Cold Style）v1.1

> 对应原型：`minimal-prototype.html`
> 风格定位：极简 / 性冷淡风（Muji / Nordic 取向）。冷调灰白、发丝级细线、大留白、无色彩。
> 设计哲学：克制、安静、不抢注意力。极简感来自**留白与细线**，而非把字压细或加装饰。
> 本次修订（v1.1）：补齐对比度合规、组件 Token 化、字号层级、状态/边界与无障碍章节。

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| 去色彩 | 全局不使用任何强调色（如蓝/橙），交互态统一用近黑 `#1c1c1c` 表达 |
| 发丝线 | 模块与设置项之间靠 1px 细线（`--line: #e9e9e6`）区分，不靠重阴影 |
| 大留白 | 内容区内边距 56px，区块间距 40–48px，呼吸感优先于信息密度 |
| 常规字重 | 正文 **400（Regular）**；**不做 300 细体**（中文小字细体发虚、费眼）。大字号本身不费眼，故大标题保持常规字重即可 |
| 克制圆角 | 结构容器仅 **4px** 圆角；**开关（Toggle）是唯一允许的胶囊例外**（业界通用形态，不视为"圆角堆叠"），其余不用胶囊、不用大圆角卡片 |
| 零投影 | 不使用 drop-shadow 投影，层次由背景色差 + 细线构建；仅允许**近黑 focus-ring**（非投影，是键盘焦点指示） |

## 二、色彩系统

| Token | 色值 | 对比度* | 用途 |
|-------|------|--------|------|
| `--bg` | `#f6f6f4` | — | 全局底色，冷调灰白 |
| `--surface` | `#ffffff` | — | 卡片 / 输入框 / 分段控件底色 |
| `--text` | `#1c1c1c` | 15.9:1 | 一级文字、激活态、主操作 |
| `--text-2` | `#595959` | 6.5:1 | 二级文字、未选中导航、正文说明 |
| `--text-3` | `#6e6e6e` | 4.7:1 | 三级文字、辅助说明、日期、占位（AA 合规最低档） |
| `--text-faint` | `#a6a6a2` | 2.6:1 | **仅装饰**：页脚版权等非信息载体，不可作为唯一信息来源 |
| `--line` | `#e9e9e6` | — | 发丝分割线、卡片边框（极淡，靠间距辅助识别） |
| `--line-strong` | `#d8d8d4` | — | 输入框 / 虚线边框、强调分隔 |
| `--hover` | `#f0f0ee` | — | 悬停底色（列表项、日历格） |
| `--focus-ring` | `rgba(28,28,28,.18)` | — | 键盘焦点环（近黑，非彩色） |
| `--disabled-text` | `#a8a8a4` | 2.5:1 | 禁用态文字（禁用态允许低对比，但需配合置灰与不可点） |

\* 对比度以 `--bg #f6f6f4` 为底测算，参考 WCAG 2.1：普通文字 ≥ 4.5:1（AA）、大字 ≥ 3:1。

**对比决策**：激活态 = 近黑文字 + 1px 左黑线（侧栏）/ 底部黑线（标签）；**不**使用色块填充。`--text-3` 已由原 `#b4b4b0`（约 1.9:1，读不清）提到 `#6e6e6e`（4.7:1，AA 合规）。

## 三、字体排版

- 字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 字重：全局 **400（Regular）**，不做 300。
- 极小字下限：**12px**（10–11px 已提至 12px，避免中文发虚）。

| 层级 | 字号 | 行高 | 字重 | 典型位置 |
|------|------|------|------|----------|
| Display 数字 | 34px | 1.2 | 400 | 番茄钟计时 |
| 页面标题 H1 | 30px | 1.3 | 400 | 起始页问候 `下午好，主人` |
| 区块标题 H2 | 20px | 1.4 | 400 | 任务页 `四象限` / `日历` |
| 模块标题 H3 | 16px | 1.5 | 500 | 卡片标题、设置分组 |
| 正文 / 标签 | 14px | 1.6 | 400 | 导航、设置项标题 |
| 辅助说明 Caption | 13px | 1.6 | 400 | 设置项描述 |
| 微文字 Micro | 12px | 1.6 | 400 | 日历数字、时间戳、版本号、页脚 |

> 层级以 **30 → 20 → 16 → 14 → 13 / 12** 的清晰跳变区分，不再用 1–2px 的微弱字号差（原 13 / 13–14 / 12 三档过挤）。

## 四、布局系统

### 4.1 全局框架

```
┌──────────┬──────────────────────────────────┐
│          │  顶部栏（crumb：起始页 / Overview） │
│ 侧边栏   ├──────────────────────────────────┤
│ 208px    │                                  │
│          │   内容区（视图：起始页/任务/设置）  │
│ 导航菜单  │                                  │
│          │                                  │
└──────────┴──────────────────────────────────┘
```

- **侧边栏**：固定 `--sidebar-w: 208px`，右 1px 细线，内边距 40px 28px。
- **顶部栏**：高 ~28px 纵向内边距，底部 1px 细线，左显示当前视图面包屑。
- **内容区**：独立纵向滚动，内边距 `--content-pad: 56px`，各视图最大宽度约 1180px。

### 4.2 三个视图

| 视图 | 结构 |
|------|------|
| 起始页 | 问候（裸文字）→ 搜索栏 → 分类标签 → 6 列应用网格 |
| 任务 | 三栏：`四象限`(1fr) · `笔记列表`(1fr) · `日历+番茄钟`(320px)，栏间距 48px |
| 设置 | 左子导航(160px) + 右内容(1fr)，子导航间距 56px |

## 五、组件规格

### 5.1 侧边栏导航
- 项目：图标（线性，20px 灰）+ 文字（14px），垂直排列，间距 2px。
- 未选中：灰字 `--text-2`；选中：近黑字 + **左侧 1px 黑竖线**（`margin-left:-12px` 对齐）。
- 品牌区：顶部大写字母距 Logo `Thrilled`。

### 5.2 问候区（起始页）
- 纯文字，**无容器包裹**（吸取早期反馈：卡片容器太抢眼）。
- 日期 12px 三级灰 → 标题 30px 一级黑 → 副文案 13px 二级灰。

### 5.3 搜索栏
- 1px 边框矩形，4px 圆角，白底，高 46px，最大宽 560px。
- 结构：`Bing 引擎标签` | `输入框` | `↵ 回车图标`。聚焦时边框转近黑 + focus-ring。

### 5.4 分类标签 / 筛选标签
- 文字按钮，底部 1px 透明线；激活态文字转黑 + 底部线转黑。
- 无背景色块，靠下划线区分。

### 5.5 应用网格
- 6 列（窄屏降为 4 列），格间距 20px。
- 磁贴：图标 46px 白底 1px 边框（悬停边框加深），下方 12px 灰标签。命中区 ≥ 44px。

### 5.6 任务 · 四象限
- 左栏四个象限：圆点（灰阶区分优先级）+ 标题 + 虚线「+ 添加任务」按钮（虚线 `--line-strong`，悬停转近黑）。

### 5.7 任务 · 笔记列表
- 筛选标签 + 列表项；每项：标题 14px + 元信息行（标签 + 日期，13px 三级灰），项间 1px 细线分隔。

### 5.8 日历 + 番茄钟
- 日历：7 列网格，今日为**实心黑圆**高亮，悬停浅灰底。
- 番茄钟：34px Display 数字 → 模式（倒计时/正计时/循环中）→ 时长（25/30/45/60）→ 开始/重置按钮。

### 5.9 设置 · 行（Row）
- 每行：左 `标题(14px) + 描述(13px 三级灰)`，右 `控件`。
- 行间 1px 细线分隔（`.row` 底部 `border-bottom: 1px solid var(--line)`）。

### 5.10 开关（Toggle）— 唯一胶囊例外
- **44×24px 圆角胶囊**轨道，开启/关闭均为胶囊形（本规范的唯一例外，见原则"克制圆角"）。
- 关闭态轨道 `--line-strong #d8d8d4`，开启态 `#1c1c1c`（近黑，非彩色）。
- 滑块白圆 20px，开启时 `translateX(20px)`。轨道高度 24px + 上下命中区补足 ≥44px 触摸目标。

### 5.11 分段控件（Segmented）
- 文字按钮组，1px 边框矩形，4px 圆角；激活态**近黑底白字**，其余透明灰字。

### 5.12 滑块（Slider）
- 细线轨道，已填充段为近黑 `--text`；手柄近黑描边 + 白心。不使用彩色。

### 5.13 输入框 / 按钮
- 输入框：白底，1px `--line-strong` 边框，4px 圆角，聚焦转黑边 + focus-ring。
- 主按钮：近黑底白字；幽灵按钮：透明近黑字 + 边框；危险按钮：灰边框灰字（克制，不红）。禁用态用 `--disabled-text` + 置灰。

## 六、间距与留白

| 场景 | Token | 取值 |
|------|-------|------|
| 内容区内边距 | `--content-pad` | 56px（左右） |
| 区块之间 | `--space-3xl` | 40–48px |
| 栏间距（任务三栏） | `--space-3xl` | 48px |
| 设置子导航与内容 | `--space-3xl` | 56px |
| 搜索栏 → 分类标签 | — | 36px（介于 `--space-xl` 与 `--space-2xl` 之间） |
| 网格磁贴间距 | `--space-md` | 20px |
| 控件内边距 | `--space-3` / `--space-4` | 12px / 16px |

节奏原则：以 **4 / 8 / 12 / 16 / 24 / 32 / 48 / 56** 为梯度（4px 基准栅格），保持视觉秩序。

## 七、交互模式

- **导航切换**：侧栏点击切换视图，面包屑同步更新。
- **设置子页**：左子导航切换右侧面板（`.spanel` 显隐）。
- **开关 / 分段 / 筛选**：即时视觉反馈，点击即切换 `active` 类。
- **悬停**：仅做边框/底色轻微变化，无位移或阴影（保持安静）。
- **焦点**：键盘 Tab 到达时显示近黑 focus-ring（`outline` 或 `box-shadow: 0 0 0 2px var(--focus-ring)`）。
- **响应式**：≤900px 任务栏转单列、设置转单列；≤760px 应用网格降为 3–4 列。
- **动效偏好**：所有过渡 ≤0.3s；`prefers-reduced-motion: reduce` 时关闭非必要动画。

## 八、状态与边界（新增）

| 状态 | 规范 |
|------|------|
| 空状态 | 居中线性图标（24px 灰）+ 13px 三级灰文案（如"暂无内容"），上下间距 24px |
| 加载 | 骨架屏：1px 圆角矩形 + 浅灰 `#f0f0ee` 占位；或细线 spinner（近黑描边） |
| 错误 / 校验 | 输入框聚焦失败边框转近黑 + 13px 三级灰错误说明；**不使用红色**（克制风） |
| 成功反馈 | 13px 三级灰"已保存" + 可选 6px 近黑圆点 |
| 禁用 | 控件置灰、不可点，文字用 `--disabled-text`；禁用态允许低对比 |
| 聚焦 | 近黑 2px focus-ring，键盘可达，鼠标点击不强制显示 |

---

## 九、无障碍合规（新增）

- **对比度**：一级 15.9:1 / 二级 6.5:1 / 三级 4.7:1，均达 WCAG AA（普通文字 ≥4.5:1）；装饰性文字须 ≥3:1 且不作唯一信息来源。
- **触摸目标**：所有交互控件 ≥ **44×44px**（开关以 44×24 轨道 + 上下命中区满足）。
- **键盘**：全功能可 Tab 到达，焦点环可见、顺序合理。
- **动效偏好**：尊重 `prefers-reduced-motion`，动画时长 ≤0.3s。
- **文字缩放**：支持浏览器 200% 缩放不破版。

## 十、设计 Token 速查（完整 CSS 变量）

```css
:root {
  /* === 配色 === */
  --bg: #f6f6f4;
  --surface: #ffffff;
  --text: #1c1c1c;          /* 15.9:1 */
  --text-2: #595959;        /* 6.5:1 */
  --text-3: #6e6e6e;        /* 4.7:1 */
  --text-faint: #a6a6a2;    /* 2.6:1 仅装饰 */
  --line: #e9e9e6;
  --line-strong: #d8d8d4;
  --hover: #f0f0ee;
  --focus-ring: rgba(28,28,28,.18);
  --disabled-text: #a8a8a4;

  /* === 字体 === */
  --font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif;
  --fs-display: 34px;
  --fs-h1: 30px;
  --fs-h2: 20px;
  --fs-h3: 16px;
  --fs-body: 14px;
  --fs-caption: 13px;
  --fs-micro: 12px;
  --lh-display: 1.2;
  --lh-h1: 1.3;
  --lh-h2: 1.4;
  --lh-h3: 1.5;
  --lh-body: 1.6;
  --weight: 400;

  /* === 间距（4px 基准栅格） === */
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-xl: 24px;
  --space-2xl: 32px;
  --space-3xl: 48px;
  --content-pad: 56px;

  /* === 圆角 / 尺寸 === */
  --radius: 4px;
  --control-h: 32px;        /* 按钮 / 输入框 */
  --switch-w: 44px;
  --switch-h: 24px;         /* 唯一胶囊例外 */
  --tap-min: 44px;          /* 最小触摸目标 */
  --sidebar-w: 208px;

  /* === 过渡 === */
  --t-fast: 0.15s ease;
  --t-normal: 0.2s ease;
}
```

> 注：本规范刻意**不使用**彩色强调变量、不使用 drop-shadow 投影。所有层级由 `--bg`/`--surface` 色差与 `--line` 细线承担；唯一允许的"发光"是键盘 focus-ring。
