## Matrix 数字雨仅中间区域有效，两边白色
- **问题**: 图片显示数字雨只有中间窄区域有效果，两边为纯白背景。根因是 `html` 设置 `display: flex; justify-content: center;` 后，`body` 作为 flex 子项的宽度由内容决定（`.container` 的 `max-width: 1200px` 限制），不会自动填满视口。而 canvas 的 `position: fixed` 因 `body { transform: translateZ(0) }` 创建了新的包含块（containing block），canvas 只能覆盖 body 的实际宽度，body 之外露出浏览器的默认白色背景。
- **修复**: `css/pixel-theme.css` 的 `html, body` 规则添加 `width: 100%`，强制 body 填满整个视口，canvas 从而铺满全屏。
- **影响文件**: `css/pixel-theme.css`(1处修改，添加 `width: 100%`)

## 磁贴（快捷方式）居中修复
- **问题**: 快捷方式磁贴没有居中显示。根因是 `pixel-theme.css` 的 `.tiles-container` 使用 `grid-template-columns: repeat(auto-fill, 110px)` — `auto-fill` 会自动用空轨道填满剩余空间，导致 `justify-content: center` 失效，磁贴实际左对齐。
- **修复**:
  - `.tiles-container`: `display: grid; grid-template-columns: repeat(auto-fill, 110px)` → `display: flex; flex-wrap: wrap; justify-content: center`，flexbox 天然支持所有行居中（包括最后一行）
  - `.tile`: `width: 100%` → `width: 110px`，配合 flex 布局使用固定宽度
  - `.add-tile-btn`: `width: 100%` → `width: 110px`，保持与磁贴宽度一致
- **影响文件**: `css/pixel-theme.css`(3处修改)

## Matrix 数字雨铺满背景修复
- **问题**: 数字雨 canvas 没有铺满整个背景——原因是 canvas 和 `#bgContainer` 都在 `z-index: -1`，DOM 中 `#bgContainer` 在 canvas 之后，导致背景容器（及其 `#bgOverlay` 遮罩）覆盖了数字雨。
- **修复**:
  - `css/base.css`: `body::before`(网格线) z-index 从 -2 改为 -3；`#bgContainer`(自定义背景) z-index 从 -1 改为 -2
  - `js/matrix-bg.js`: 列数计算从 `Math.floor(w / fontSize)` 改为 `Math.ceil(w / fontSize)`，确保最右侧不留空白
  - Canvas 保持在 `z-index: -1`(JS 中设定)，现在层叠顺序为：网格线(-3) → 自定义背景(-2) → 数字雨(-1) → 页面内容(默认)
- **影响文件**: `css/base.css`(2处修改)、`js/matrix-bg.js`(1处修改)
