# 2026-07-17

## v2.25.0: 新增专注模式完整数据导入导出功能

- **导出**：设置 → 数据与备份 → 「导出全部数据」按钮，调用 `dataService.exportAll()` 获取完整快照（笔记/任务/捕获/磁贴/配置），生成 JSON Blob 触发下载
- **导入**：「导入备份数据」按钮，支持 v3.0 完整快照格式（通过 `dataService.importAll()` 写入 chrome.storage.local），导入后自动刷新页面
- **兼容**：保留旧版磁贴备份格式的导入逻辑

## v2.25.1: 修复导入备份时四象限任务不显示

**根因**：`getWorkbenchState()` 只读 localStorage `devhome_workbench`，而 `dataService.importAll()` 只写 `chrome.storage.local` 的 `v2/tasks`。两套存储不同步导致导入后任务不显示。

**修复**：在 `_importBackupData` 中 `importAll()` 完成后，新增 `_syncTasksToWorkbench()` 将 v2 扁平任务数组 `[{id, quadrant, ...}]` 转换回四象限格式 `{quadrants: {q1: {tasks: [...]}, ...}}`，写入 `localStorage devhome_workbench`。

**修改文件**：
- `js/ui/_settings-panel.js` — 新增 `_syncTasksToWorkbench()` 辅助函数
- `manifest.json` — 版本号 2.25.0 → 2.25.1
- `index.html` — 版本号 + changelog 条目

**修改文件**：
- `js/ui/_settings-panel.js` — 新增 `exportBackupData()`（导出）和 `_importBackupData()`（导入）函数
- `js/events/misc-events.js` — 重写 `_bindImportEvents()`，优先使用新导入入口
- `index.html` — 版本号更新至 v2.25.0，新增 changelog 条目
- `manifest.json` — 版本号 2.24.0 → 2.25.0

**数据迁移方案**：用户可将旧浏览器数据导出为 JSON → 复制到新设备 → 导入，解决 chrome.storage.local 不跨设备同步的问题
