# 2026-06-11

## 修改快捷方式打开行为：新标签页 → 当前页打开

**需求**: 点击快捷方式不要新开页面，直接在当前页面打开。

**修改文件**:
- `popup.js`: `openItem` 函数中将 `window.open(url, '_blank')` 改为 `chrome.tabs.update(tabs[0].id, {url})`，在当前活跃标签页打开链接和文件。
- `script.js`:
  - 磁贴 `<a>` 元素 `target` 从 `_blank` 改为 `_self`
  - `openUrl()` 函数中 `window.open(url, '_blank')` 改为 `window.open(url, '_self')`
  - `applySuggestion()` 中对磁贴建议的打开也改为 `_self`
