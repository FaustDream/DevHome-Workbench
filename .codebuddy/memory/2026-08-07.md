## 16:45 - 弹窗按钮失效根因修复（fix）

### 任务描述
新增磁贴弹窗的添加/取消/×按钮全部无效果。

### 根因（P0）
**类名冲突**：`tiles.ts` 空状态「+ 添加快捷方式」按钮 `className='ui-btn ui-btn-primary hidden-message-add'` 中的 `ui-btn-primary` 类，与弹窗确认按钮 `.ui-btn-primary` 完全相同。
- `document.querySelector('.ui-btn-primary')` 在 DOM 顺序上匹配到**页面上的空状态按钮**（而非弹窗确认按钮）
- 点击「添加」实际又触发 `promptAddTile` → **又开一个弹窗**，弹窗堆积不关闭

另有一层隐患：`#dhDialogHost` pointer-events 可能被 showToast 设为 none 阻断点击（已防御性修复）。

### 修复
1. **移除空状态按钮的 ui-btn-primary 类**（`tiles.ts`）→ 改为独立类 `hidden-message-add`
2. **新增独立按钮样式**（`css/empty-state.css`）：蓝底圆角胶囊，对齐 ui-btn-primary 视觉
3. **防御性修复**（`dialogs.ts`）：
   - `createOverlay` overlay 设 `style.pointerEvents='auto'`（host 保持 none，弹窗按钮可点）
   - `showToast` 不再修改 host pointer-events（改由 toast 自身 auto）

### 浏览器实测

- 取消：✅ overlays=0 + 磁贴不新增
