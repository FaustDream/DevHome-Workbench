### 样式不生效修复 (v2.24.0)

**问题**: 用户从旧版升级后样式全无，页面显示未应用 CSS 状态。

**根因**: Chrome 扩展缓存了旧的 `theme-manager.js`，旧版本会按 `state.themeFamily` 禁用/启用 `<link>` 元素。当 `localStorage` 保存的旧 themeFamily（如 'default'）与新 HTML 不匹配时，旧的逻辑会禁用 `minimal.css`（旧版没有这个 link），导致新 HTML 没有布局 CSS。

**修复**:
- 给所有 CSS/JS 引用添加版本号缓存破坏参数：`?v=2.24.0`
  - `css/fonts.css?v=2.24.0`
  - `css/themes/*.css?v=2.24.0`
  - `js/theme-manager.js?v=2.24.0`
  - `js/navigation.js?v=2.24.0`
  - `js/main.js?v=2.24.0`
  - `js/ui.js?v=2.24.0`
- 重新设计 `applyThemeFamilyToDOM()`：`minimal.css` 始终启用作为布局基础，`default.css` / `skeuomorphic.css` 作为可选叠加层
- 0 lint 错误
