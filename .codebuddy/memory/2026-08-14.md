- 移动后停留原分类（不自动跳转），通过撤销 toast 让用户恢复，撤销逻辑简单

- 撤销是单一动作（最近一次），`undoAction` 覆盖删除和移动两种类型
- `moveTilesBetweenPages` 无变化时返回原引用，用于 `===` 判断跳过 save

## 修复 3 个快捷方式管理 Bug

### Bug 1：移动分类弹窗无分类选项
- 根因：`promptMoveToCategory` 过滤当前分类后，单分类场景 `targets` 为空，走"暂无分类"提示而非分类列表；分类名后置写入（脆弱）
- 修复：分类名内联渲染（新增 `escapeHtml` 防注入）；新增「新建分类」入口（`moveTilesToNewPage`：创建分类+移动+撤销，不切换当前页）；空态提示
- `tiles.ts` 新增 `import { renderCatRow } from './category-ui'`（与 category-ui 形成循环依赖，但双方均为函数内运行时引用，esbuild 打包安全）

### Bug 2：拖拽磁贴变宽 + 图标位置错误
- 根因：`.tile { width: 100% }` 遇到 `position: fixed` 脱离网格流后宽度坍缩为视口宽
- 修复：`positionDragTile` 显式设置 `width`/`height` 为原始 rect 尺寸；`resetDragState` 同步重置 width/height

### Bug 3：批量操作栏视觉反馈缺失
- 根因：`.tile-selected`/`.cat-btn.tile-drop-over` 用到的 `--color-accent-bg-30` 未定义，`box-shadow` 整条失效
- 修复：在 `tokens.css`（fallback）、`themes/default.css` 浅色/深色模式补齐 `--color-accent-bg-30`（深色模式还补齐了缺失的 `-bg-18`）

### 关键教训
- 引入新 CSS 变量前必须确认在 tokens.css + 主题浅色/深色两处都有定义，否则 `var()` 未定义会导致整条声明失效（静默降级为 initial）
- 深色模式 token 覆盖不全（缺少 -18/-30），新增 token 时需三处同步
- 已执行 `npm run build` 重新生成 dist/ 产物
