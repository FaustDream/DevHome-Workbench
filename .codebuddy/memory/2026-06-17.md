## Bug 修复：拖拽磁贴后重启位置恢复默认

- **根因**: `tileManager.reorder()` 改变数组顺序后未更新 `position` 字段，`remove()` 同理。保存到文件/localStorage 的数据 position 是旧值。重启时 `sortByPosition()` 按旧 position 排序，恢复拖动前顺序。
- **修复**: `js/tiles.js` `tileManager.save()` 开头加 `this.currentTiles.forEach((tile, idx) => { tile.position = idx; })`，每次保存前将 position 同步为数组下标。
- **影响**: 新增/删除/拖拽重排均正确持久化到文件。
- **影响文件**: `js/tiles.js` (+3行)
