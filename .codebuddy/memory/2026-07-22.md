## v2.29.1 紧急修复（聚焦模式布局混乱 + CSP 拦截）

### 1. 顶部工具栏布局修复
- **问题**：原 v5 顶部工具栏用 `display:flex` 单行排版，pomodoro + 搜索 + 笔记本下拉 + 操作按钮 + 过滤器 + 设置按钮全挤在一行；同时由于 dailymode-btn 用 `margin-left:auto` 占据整行空间，导致 `.wb-notes-layout` 笔记区域被挤压/看似消失
- **修复**：
  - `css/workbench-layout.css`：`.wb-topbar` 改为 `flex-direction: column`，新增 `.wb-topbar-row` 显式分行容器
  - `index.html`：第 1 行放番茄钟常驻条 + 日常模式设置按钮，第 2 行放笔记工具栏
  - 移除重复的 dailymode-btn（原本两处）
- **效果**：笔记区域 `.wb-notes-layout` 恢复正常 `flex:1` 扩展，左侧四象限+日历、顶部两行工具栏、笔记列表+编辑器的层级关系清晰

### 2. CSP 拦截修复（home.streamlinehq.com favicon 报错）
- **现象**：控制台报 `Connecting to 'https://home.streamlinehq.com/favicon.ico' violates... connect-src 'self' https://api.bing.com/ ...`
- **根因**：原 `connect-src` 只放行白名单域名，但 v2.27.6 引入的 SW 抓取任意域 favicon 的能力需要放行 `https:`
- **修复**：
  - `manifest.json` 的 `content_security_policy.extension_pages.connect-src` 增加 `https:`、`http://localhost:*`、`ws://localhost:*`
  - 新增 `content_security_policy.service_worker` 字段，SW 的 `connect-src` 也放行 `https:`/`http:`
  - 实际可访问的源仍由 `host_permissions` 控制，CSP 只是声明 fetch 协议
- **提交**：`56adf58` 已 push 到 main
- **注意**：扩展更新后必须重新加载，CSP 变更不会热更新

## v2.29.2 v6 悬浮式布局重构

### 核心设计变更
- **v5 之前**：左侧 docked 侧边栏（35% 宽，固定占布局空间）
- **v6 现在**：**悬浮式侧边栏**（44px 宽，position: fixed）+ 悬浮面板（position: fixed）+ 笔记区**占满整个视口**

### 关键设计原则（用户要求）
1. 左侧侧边栏改为**悬浮式**（脱离文档流，position: fixed），仅 44px 宽
2. 仅含 2 个图标：番茄钟 + 四象限任务
3. 笔记区默认**全屏展示**，占满整个视口高度
4. 悬浮元素**严禁出现遮罩层**
5. 悬浮元素采用 position: fixed，**完全脱离文档流**
6. 悬浮元素**不影响笔记区域**现有布局和尺寸

### 实现细节
- `wb-shell` 改为单列 `grid-template-columns: 1fr`
- 笔记区 `wb-main` 占满 100% 宽
- 左侧添加 `wb-floating-sidebar`（44px 宽，position: fixed）
- 点击图标弹出 `wb-floating-panel`（360px 宽，紧贴侧边栏右侧）
- 移除 docked 左侧栏、四象限标题区、日历
- 退出专注按钮移到悬浮侧边栏底部
- 顶部工具栏移除原 pomodoro popover（避免与悬浮面板 ID 冲突）

### 事件行为
- 点击悬浮侧边栏图标 → 打开对应悬浮面板（互斥）
- 点击面板关闭按钮 → 关闭
- 点击页面空白处 → 关闭打开的悬浮面板
- Esc 键 → 关闭打开的悬浮面板
