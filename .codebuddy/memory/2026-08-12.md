## 快捷方式图标 fallback 改为纯色背景

移除了 Google favicon 服务兜底（该服务对无 favicon 的站点返回默认地球图标），改为纯色背景显示。

### 修改的文件
- `src/background/favicon-resolver.ts` — 移除 Google favicon 兜底逻辑，仅尝试 `favicon.ico`
- `src/pages/index/favicon.ts` — `tryGoogleFaviconFallback` 移除；`showLetterFallback` 替换为 `showColorFallback`，使用磁贴 color 属性作为背景色；`loadFavicon` 新增 `color` 参数
- `src/pages/index/tiles.ts` — `buildTileElement` 中传递 `tile.color` 给 `loadFavicon`
- `css/tiles.css` — 新增 `.tile-icon-fallback` 样式，纯色背景 + 圆角 + 85% 透明度

### 重要：修改源码后必须重新构建 dist/
`manifest.json` 指向 `dist/` 目录的产物。修改 `src/` 源码后必须运行 `npm run build` 重新生成 `dist/`，否则浏览器加载的仍是旧代码。本次问题根因就是修改了源码但未重新构建。

## 项目全面功能审查

对全部 40 个 TS 源文件、11 个 CSS 文件、3 个 HTML 页面及 manifest.json 进行了全面审查，识别可移除/废弃/冗余模块。

### 关键发现
- **剪藏功能**：后台右键菜单保存数据到 v2/captures，但新标签页无任何 UI 消费这些数据，属于"写入但永不展示"的死代码
- **工作台模块**：`QuadrantTask`、`BehaviorState` 类型 + index.html 中隐藏的 `#wbSettingsStatsWrap` / `#reactDashboardRoot` + 事件总线 `WORKBENCH_ENTER/EXIT` — 均已是废弃残留
- **侧边栏**：`sidepanel.html` 仅有骨架文案，无 JS 入口，build.mjs 不为其打包
- **features.css Bug**：`popup.html` 和 `sidepanel.html` 引用了不存在的 `css/features.css`
- **未使用的 manifest 权限**：`alarms` 权限无代码使用
- **未使用的常量/函数**：`PAGE_BACKUP_LIMIT`、`GOOGLE_FAVICON_SERVICE`、`DATA_SERVICE_CACHE_TTL_MS`、`CLOCK_UPDATE_INTERVAL_MS`、`LAYOUT_PRESETS`、`DEFAULT_LAYOUT_CONFIG`、`formatTaskTime()`、`formatSeconds()`、`checkQuota()` — 均仅定义无调用
- **事件总线过度设计**：15 个事件名中仅数字键切换引擎实际使用

### 可立即安全移除的条目（13 项类型/常量/函数）
详见会话中的完整评估清单。
