## 修复：主题系统重构导致专注模式样式/功能全部失效

**根因分析（3 个）**：

1. **命名空间错误（致命）**：`theme-manager.js` 将主题挂载到 `window.ns`，但 `main.js` 检查的是 `window.DevHome.theme`，导致 `ns.theme.init()` 从未执行，主题切换和 CSS 色值恢复全部失效。

2. **workbench.css 硬编码暗色专用值**：四象限卡片、任务项等使用 `rgba(255,255,255,...)` 硬编码半透明白色，仅适合深色背景。切换到浅色主题后白底白字不可读。

3. **缺失 subtle/muted 表面色令牌**：没有定义跨主题的浅层表面色（`rgba(255/0,255/0,255/0,0.02~0.06)`）语义变量。

**修复（6 文件）**：

- `js/theme-manager.js`: `window.ns` → `window.DevHome` 修复命名空间
- `css/tokens.css`: 新增 `--color-surface-subtle` / `--color-surface-muted` 令牌声明
- `css/themes/default.css`: 添加 2 个 Pride+2 个 Semantic 赋值在 `:root`/`[light]`/`[dark]` 三个块
- `css/themes/warm-paper.css`: 添加 2 个 Pride+2 个 Semantic 赋值
- `css/themes/hacker.css`: 添加 2 个 Pride+2 个 Semantic 赋值（荧光绿透明层）
- `css/themes/pixel.css`: 添加 2 个 Pride+2 个 Semantic 赋值（荧光绿透明层）
- `css/workbench.css`: 13 处 `rgba(255,255,255,...)` 替换为 Semantic 令牌
