## 修复：左上角问候区域样式消失 + 重置弹窗层级 + 书签自动分类

### 任务描述
修复三个用户反馈的问题：
1. 左上角天气、日期、问候样式消失
2. 设置面板"重置所有设置"弹窗被侧边栏挡住
3. 收藏夹导入的书签未按子文件夹自动分类

### 关键决策
1. **问候样式**：将 `.dh-greeting-area` 等缺失 CSS 添加到 `css/time-search.css`（该文件已有问候/天气相关样式），使用 `position: fixed` 左上角定位，遵循 Semantic Token 体系引用 `var(--color-*)` / `var(--font-size-*)` / `--text-shadow-strength` 等变量。
2. **弹窗层级**：`#dhDialogHost` z-index 从 2800 → 3200，`.ui-overlay` 同步更新。原因是设置面板 z-index=3001，原 2800 会被面板遮挡。3200 位于面板(3001)之上、Toast(3500)之下，层级合理。
3. **书签分类**：重写 `buildPagesFromBookmarks()`，将收藏夹栏子文件夹拆为独立分类（而非全部平铺到一个分类）；直接书签归入「第1页」；显式跳过「其他书签」(id="2")和「移动设备书签」(id="3")；`BookmarkNode` 接口增加 `exactOptionalPropertyTypes` 兼容（属性加 `| undefined`）。

## 修复：书签导入后分类名不显示 + UI 不刷新

### 任务描述
上一轮修复了 `buildPagesFromBookmarks()` 的分类逻辑，但导入后分类按钮行（catRow）不显示名称且磁贴也没有渲染。根因是 `persistPages()` 遗漏了 `state.pageNames` 的赋值 + 导入完成后未调用 UI 重渲染。

### 关键决策
1. **`persistPages` 补充 `state.pageNames`**：原代码只写了 `state.pagesData` 和 `state.totalPages`，但 `renderCatRow()` 渲染分类栏依赖 `state.pageNames`，导致分类按钮行为空。
2. **导入完成后显式刷新 UI**：onboarding 在 boot Phase 2.5 执行，Phase 2 已提前渲染了空的分类行和磁贴容器。`persistPages` 现在内部调用 `tileManager.updateCurrentTiles()` 同步当前页磁贴，外部调用 `renderCatRow()` + `renderTiles()` 重绘 DOM。

### 变更摘要
- [修改] `src/pages/index/onboarding.ts` — 新增导入 `tileManager`/`renderTiles`/`renderCatRow`；`persistPages` 补全 `state.pageNames` + `tileManager.updateCurrentTiles()`；主流程末尾加 `renderCatRow()` + `renderTiles()`
